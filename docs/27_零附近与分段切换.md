# 第27讲：零附近、负幂与分段切换

前置内容：[有限时间面内关系](26_有限时间面内关系.md)、[输出限幅](13_输出限幅怎样改变趋近关系.md)。本讲检查实际表达式在哪里有定义，以及分段公式切换时发生什么。

## 1. 奇异性是什么

**奇异性是指某些有限输入处，表达式没有定义，或靠近该输入时某个量无界。** 例如0不能作为普通除法的分母；e趋近0时 `1/sqrt(|e|)` 会越来越大。

终端外区公式中的系数为：

```text
beta*a*|e|^(a-1)
```

取beta=2、a=.5：

| 误差绝对值 / rad | 该系数 / (1/s) |
| --- | ---: |
| 1 | 1 |
| .01 | 10 |
| .0001 | 100 |
| 0 | 原式无有限定义 |

该系数还要乘速度误差v。不能只看系数无界就断言任何运动都必须产生无限电流：乘积还取决于v怎样变化。但通用控制输入不能假定当前状态恰好沿某一理想关系运动；原表达式在e=0仍需要明确处理。

直接在浮点计算中令e=0，系数得到无穷；v=0时再乘它会产生无效数值，v非零时可能产生无界请求。这不是用最终输出限幅就能补回的公式定义。

## 2. 先选分支，再计算

本库使用明确的分段关系：

```text
|e|<delta：普通位置分支，h=c*e，h_derivative=c
|e|>=delta：终端分支，h=beta*sign(e)*|e|^a
                          h_derivative=beta*a*|e|^(a-1)
```

delta是调用方给定的正误差阈值，单位与位置误差相同。它不是隐藏的实机默认参数。内区不计算负幂或1/e，不先算无效值再覆盖；这个顺序实现的是所声明的分段公式。

当e=0、v=1rad/s时，仍需要改变运动。本讲参数b=2、c=4、K=3、epsilon=4、phi=2，得到s=1、请求−4.5A，而不是看到位置误差为0就直接输出0。

## 3. 原参考的实际差别

参考C的源码先计算含 `e_qp/error` 的终端请求，再在 `abs(error)<1` 时用普通公式覆盖。如果此前的死区没有返回，危险表达式已经执行；死区设为0时，零误差可以走到未定义运算。先覆盖输出不等于没有执行前面的表达式。

C的原阈值1依附于角度单位°。本库示例的delta=.25rad只是教学参数，不能把数值1从度直接照搬到弧度。内区c与外区beta也分别配置，因为它们单位不同。

参考B的TFSMC分支在位置误差为0时直接令u=0；它没有把这时的速度误差或目标加速度一起考虑。当前库内区保持完整计算。

本轮还只读检查了B的sliding.slx内部：名为tfsmc的实例映射到chart_62，其公式为 `J*(dwd-c*e-epsilon*sign_s-k*s)`；对应s1映射chart_76，关系为 `s=e+c*se`。这实际是速度误差累计结构，不能因为模块名为tfsmc就当作终端误差幂的验证。本轮未运行原Simulink模型。

## 4. 两侧数值接得上，电流也一定接得上吗

**接续在这里指从阈值两侧接近时，函数值趋向同一个值。** 选择 `c=beta*delta^(a-1)` 可以让两侧h值接续。

取beta=2、a=.5、delta=.25rad、c=4/s，正阈值处：

```text
普通侧h=4*.25=1rad/s
终端侧h=2*sqrt(.25)=1rad/s
普通侧h_derivative=4/s
终端侧h_derivative=2/s
```

因此s=v+h虽然接续，控制请求中 `-h_derivative*v/b` 仍可能改变。沿用v=1rad/s、b=2及上节K、epsilon、phi：

```text
阈值下侧：s≈2，请求≈(-4-6-4)/2=-7A
恰好阈值：s=2，请求=(-2-6-4)/2=-6A
```

输出范围在这个检查中设为±100A，仅为观察原始差别，不表示实际设备允许值。若把两边都限制成相同电流，就会掩盖约1A的请求跳变。

本库没有插入平滑插值或切换迟滞，也不擅自改c。当前字段terminal_branch明确记录实际使用的分支；用户可以依据该定义评价是否适用于具体任务。

## 5. 实验怎样覆盖零与阈值

本讲给出正负误差，从10^-30到10^-2rad，以及零和±delta两侧相邻的单精度数；每个误差分别使用v=0与1rad/s，共466个公式点。

**相邻浮点数是当前精度下紧挨某个数、可以表示的前一个或后一个数值。** 因此检查不仅是随意取delta±.001，而是直接检查分支边界紧邻处。等于阈值使用终端分支，小于阈值使用普通分支。

原负幂系数与实际分段系数分开绘图。图轴按倍数分格，以同时看见极小误差和巨大系数；零点不放进这种正数坐标轴，而是单独检查原式无定义、本库内区输出有限。

另外运行正向b=3与反向b=−3的两组完整对象实验，声明对象与控制器方向一致，核对相同运动与相反电流，不猜测真实电机方向。
