# 第26讲：有限时间到零与一直逼近零

前置内容：[面内误差怎样变化](07_面内误差怎样变化.md)、[混合幂次趋近](25_混合幂次趋近规律.md)。本讲区分数学结论、生产分段公式和数值实验。

## 1. 有限时间到零是什么意思

**有限时间到零，是指存在一个有限的T，在该时刻到达零，并在所讨论的关系下保持为零。** 指数衰减则可能越来越小，却在任意有限时刻仍不等于零。

例如普通面内关系 `e_dot=-c*e` 的解为 `e=e0*exp(-c*t)`。c>0、e0非零时，有限t对应的指数仍为正；图像看起来贴着零线，不等于数学上已经严格到零。

“有限时间稳定”还要求稳定性，不能只凭某条曲线碰到零就作结论。定义可核对Bhat与Bernstein的原始论文[Finite-Time Stability of Continuous Autonomous Systems，定义2.2及命题2.3](https://www.aero.iitb.ac.in/~bhat/siam_fts.pdf)。本讲只对下面明确的一维理想关系推导到达时间。

## 2. 带符号误差幂是什么

**带符号误差幂，是先对误差绝对值求幂，再恢复原来正负号的函数**：

```text
g(e)=sign(e)*|e|^a，0<a<1
```

以a=.5为例，e=4得到2，e=−4得到−2，e=0得到0。这样不会直接对负数求通常不存在实数结果的平方根。

**终端滑模面是用这类非线性误差关系研究面内有限时间收敛的滑模面。** 本讲取：

```text
s=v+beta*g(e)
```

e仍是位置误差，v是对应速度差；beta为正系数，单位 `Q^(1-a)/s`，s单位Q/s。若已经在理想面上并一直保持s=0，则：

```text
e_dot=-beta*sign(e)*|e|^a
```

“已经在面上”是前提。例如e0=1rad、beta=2、a=.5时，对应v0=−2rad/s，而不是默认v0=0。

## 3. 到达时间从哪里来

对正误差令x=e，对负误差令x=−e，也就是x=|e|；两侧都满足：

```text
x_dot=-beta*x^a
```

在x>0时，将x的幂移到一侧，再按时间累计，可得：

```text
x^(1-a)=x0^(1-a)-beta*(1-a)*t
T=|e0|^(1-a)/[beta*(1-a)]
```

因此完整解分为两段：

```text
t<T：e=sign(e0)*[|e0|^(1-a)-beta*(1-a)*t]^(1/(1-a))
t>=T：e=0
```

本讲教学取e0=±1rad、beta=2、a=.5，T=1s。正初值对应 `(1-t)^2`，负初值取其负值，到T后为0。MATLAB使用这个解析分段解并核对变化率，没有先做数值积分再把小误差强制清零。T依赖初始误差，这个1s不代表所有初值都用同样时间。

## 4. 为什么生产库不能照搬这个保证

当e非零时，带符号幂的变化率包含 `a*|e|^(a-1)*v`。a<1使负指数出现；它在零附近的行为留到第27讲详细检查。

本库TerminalPosition沿用参考C的大误差终端、小误差普通结构：|e|<delta时改用 `s=v+c*e`，其余使用终端关系。所有系数和delta都由调用方提供，先选分支，再计算相应公式。

用本讲教学参数beta=2、a=.5、delta=.25rad、c=4/s，假设始终满足相应面内关系：从e0=1到delta需.5s，进入内区后：

```text
e=.25*exp[-4*(t-.5)]，t>=.5
```

在纯终端解到零的T=1s，分段面内解仍约为.0338338rad；它在有限时间内仍非零。生产控制的s本身又使用连续sat处理，因此不能仅凭“终端”名称推出全程严格有限到零。

图中的纯终端、普通和分段面内关系用于辨析解析形式，不是相同物理初始速度下的控制性能竞赛。完整闭环另使用b=3、目标.5rad、初始角度−.2rad和速度0、输出±4A的教学对象，单独记录实际结果。

## 5. 源码对应与运行

参考C的推导与实现选取带符号误差幂；参考B的TFSMC分支也含该结构。名称中的“快速”不能代替公式分类，本库只称终端/普通分段形式。库直接接收指数a，不用两个未检查的分子分母参数来间接构造它。

完整控制请求为：

```text
request=(r_ddot-h_derivative*v-K*s-epsilon*sat(s/phi))/b
```

h在内区为c*e，外区为beta*g(e)；导数按各自分支计算。仍保留显式目标加速度、方向系数和输出限制。接口与单位见[扩展规格](位置扩展数学规格与接入说明.md)。
