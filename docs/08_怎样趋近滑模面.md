# 第 08 讲：还没到滑模面时，应该怎样运动

前置内容：[滑模变量与滑模面](06_滑模变量与滑模面.md)、[面内误差怎样变化](07_面内误差怎样变化.md)。本讲只规定并检查滑模变量的变化方式，尚不计算让真实电机实现它的电流。

## 1. 先分清这次研究的量

e 是角度误差，单位 °；ė 是误差变化率，单位 °/s；c 为正系数，单位 1/s。滑模变量为 `s=ė+ce`，单位也是 °/s；s=0 对应滑模面。

上一讲假设 s 已经始终为零。本讲研究 s 还不为零时，应该让它怎样变化。

**趋近律是对滑模变量 s 随时间怎样向零靠近的规定。** 直观上，s 为正时要让它减小，s 为负时要让它增加。

**ṡ 是 s 本身随时间的变化率**，单位 °/s²。它与 ė 不同：一个描述 s 怎样变化，另一个描述位置误差 e 怎样变化。ṡ 也不是电流，不能因单位相同就直接等同于电机角加速度。

## 2. 先定义符号函数

**符号函数只根据输入的正负返回一个数。** 记为 sign(s)，这里约定：

| 输入 | 返回值 |
| --- | ---: |
| s>0 | +1 |
| s=0 | 0 |
| s<0 | −1 |

返回值没有单位，它只区分方向，不保留 s 的大小。MATLAB 的 sign() 使用这一定义。

例如 s=6 或 s=2 时，都返回 +1；s=−6 或 s=−2 时，都返回 −1。

## 3. 参考中采用的规则

引入两个参数，均取正值：K 的单位为 1/s；epsilon（ε）的单位为 °/s²。这样 `K×s` 和 `ε×sign(s)` 都是 °/s²，可以相加。

选取：

```text
ṡ = -K × s - ε × sign(s)
```

参考称它为“指数趋近律”。本讲只研究这一种形式。K 与上一讲的 c 不同：c 用来规定误差和变化率组成哪条面；K 在这里参与规定 s 靠近零的方式。

先分别检查两侧：

- s>0 时，sign(s)=+1，得到 `ṡ=−Ks−ε<0`，所以 s 减小。
- s<0 时，sign(s)=−1，得到 `ṡ=−Ks+ε>0`，所以 s 增加。
- s=0 时，按 sign(0)=0 给出 ṡ=0，本讲采用到零后理想保持零的约定。

负号没有“直接让电机反转”的含义；这里规定的是 s 的变化方向。它与实际控制电流怎样联系，留给下一讲推导。

## 4. 用数字核对方向

以下仅为教学假设：K=1 /s，ε=2°/s²。

| 当前 s / (°/s) | sign(s) | −Ks | −ε·sign(s) | 要求的 ṡ / (°/s²) |
| ---: | ---: | ---: | ---: | ---: |
| −6 | −1 | +6 | +2 | +8 |
| −2 | −1 | +2 | +2 | +4 |
| 0 | 0 | 0 | 0 | 0 |
| +2 | +1 | −2 | −2 | −4 |
| +6 | +1 | −6 | −2 | −8 |

两项都在推动非零 s 朝零改变。s 很小时，−Ks 的大小会减小，但符号项的大小仍为 ε；这是这条理想规则与上一讲单纯比例变化关系不同的地方。

也可做第 4 讲的一步近似：s=2°/s 时要求 ṡ=−4°/s²，若只向前算 .1 s，则下一值约为 `2−4×.1=1.6°/s`。负侧 s=−2 同样约变为 −1.6。本讲不把这一步近似扩展为任意间隔下都能精确到零的结论。

## 5. 本讲的理想 s 时间曲线

为了核对规则，先只把它作为理想数学关系，假定能够被准确实现。使用上一讲的 exp 函数，可以求到达前的时间曲线。

t 表示从观察开始经过的时间，单位 s；s0 是初始滑模变量，单位 °/s；`|s0|` 表示不带正负的大小。max(a,0) 表示从 a 与零里取较大的数。

本讲独立整理的分段表达为：

```text
q(t) = (|s0| + ε/K) × exp(-K×t) - ε/K
s(t) = sign(s0) × max(q(t), 0)
```

其中 q 的单位为 °/s。q 还为正时按前一条曲线运动；q 降至零后，后一条表达按理想约定保持 s=0。max 在这里表达数学解的两个阶段，不是把逐次计算越过零后的数值随意改为零。

可以检查正侧到达前的变化率：

```text
ṡ = -K × (s0 + ε/K) × exp(-K×t)
   = -K × s(t) - ε
```

它正好满足 s>0 分支；负侧由相反符号得到。到达的切换时刻，两侧变化率不同，本实验只在到达前核对解析变化率，到达后采用保持零的约定。

初值取 +6、−6、0°/s，观察 4 s。正初值的曲线在 1 s 时约为 .943036°/s，在取点时刻 1.38 s 尚未为零，到 1.39 s 已按分段解保持零，因此理想到达发生在这两个取点时刻之间。1.39 s 不是精确到达时刻。

还有一个不用求精确时刻的检查：在到零前，|s| 的减少速率至少为 ε。初始大小为 6、ε=2，最多 3 s 就应到零；K 项使本例实际更早到达。这只针对本节理想规则。

## 6. 到达 s=0，与误差 e 到零不同

这条理想趋近律使非零 s 在有限时间到零，含义是到达滑模面；它不等于位置误差同时归零。

第 6 讲已经见过 s=0、e≠0 的点。若到达之后又始终保持线性滑模面关系，误差仍按第 7 讲的关系逐渐接近零。不能把 s 的到达性质直接当成 e 的到零性质。

本讲只画 s(t)，没有重建完整的 `(e,ė)` 轨迹，也没有计算电流，因此不会给出某台机器人已经实现到达的结论。

## 7. 与开源和生产库的对应

复旦新版 [README.md](../smc/README.md) 第 145～148 行给出 `ṡ=−ε·sgn(s)−Ks`；sgn 与本讲 sign 是同一个符号函数的记法。川大 [SMC_Doc.tex](../Sliding/Documentation/SMC_Doc.tex) 第 118 行和第 127 行也采用该规则。

复旦旧版 [slidingmodec.h](../SMC_Controller/SMC/slidingmodec.h) 第 44～51 行的 Signal() 实现正/零/负返回 1/0/−1；但控制代码实际通过 Sat() 在零附近进行连续处理，不能认为有 Signal() 就是在所有地方直接使用符号函数。

当前库 [ALG_SMC.hpp](../main/ALG_SMC.hpp) 的 reaching_gain 对应 K、switching_gain 对应 ε。实现 [ALG_SMC.cpp](../main/ALG_SMC.cpp) 第 93～103 行在零附近同样采用连续处理，细节在后续相关讲次介绍。因此不能把本讲理想符号函数的有限时间到达直接记为生产库性能。
