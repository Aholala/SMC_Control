本页记录个人学习计划与学习进度。算法库是否完成见独立的[库建设计划](算法库建设计划与进度.md)。资料已经生成、程序已经运行或库已经实现，都不等于个人已经学会。

2026-10-29 用户要求先完成库、再教学。普通位置首版已实现并完成主机、MATLAB 独立核对和 ARM 交叉编译；当前已建立并运行第 1～9 讲，其他课次仍为规划。每次说“下一步”或“继续”，只推进一个能理解、能运行、能验证的小步骤；若某一讲仍太大，再拆小，不按编号赶进度。

第 19～22 讲到来时以现有库进行逐项阅读与实验，不重复维护另一份生产实现。当前库说明见[库接入与验证说明](库接入与验证说明.md)。

## 1. 每一步的固定交付

1. 一份中文讲义：先定义，再给直观理解和简单例子，最后按需要引入公式与代码。
2. 明确前置知识；公式中的符号、单位和假设逐项说明。
3. 一个 MATLAB 入口：写清教学主题、如何运行、参数含义和预期观察。
4. 一个小检查：先核对简单数值、符号或基本行为，再观察曲线；检查项目必须与当前概念相符。
5. 源码对应：指出参考路径、函数及相关语句；新推导或新实现与原参考不同的地方明确标记。
6. 真实运行记录：记录版本、命令、参数、结果；无法运行就标记“未运行”，不从阅读推出“已可用”。

教学参数用于解释现象，标为“教学假设”。原作者工程参数单列来源；机器人真实参数必须由使用项目提供。

每个实验写明：主题、前置知识、运行入口、MATLAB/工具箱依赖、参数名称/单位/来源、预期现象、检查条件、实际结果。输出归入 `build/` 的对应中文用途目录，保留参数和日志。

与 C++ 核对时，MATLAB 自己按明确的公式计算；C++ 主机程序调用生产库输出数据。两边共享输入序列和公式规格，不把 C++ 输出直接读入 MATLAB 再称为“独立算法核对”。允许差异必须按数值精度、计算尺度和累计过程确定，不能事后放宽阈值掩盖错误。

## 7. 最基础的起点

起点是第 01 讲“角度和角速度分别是什么，怎样联系”，当前按用户“继续”推进到第 09 讲“从运动关系推导控制输入”。

原因：三份位置控制代码都同时使用角度和角速度。先弄清它们的物理含义与单位，才能理解误差及其变化率；再往后才能理解为什么滑模变量要把这两类量联系起来。

首个实验只研究给定角速度时角度如何变化，并用手算核对结果。不加入控制器、调参、外力或算法变种，以免同时引入多个尚未理解的主题。

## 9. 必要时使用的理论补充

主线以三个本地参考和独立推导为基础。遇到稳定性条件或命名歧义时，使用原作者教材/论文与官方课程核对，不把博客或 README 宣传当成证明。

- [MIT Slotine 官方课程目录](https://www.mit.edu/~nsl/videos/lectures.html)：第 6 讲 Sliding Variables、第 7 讲 Robust Control，对应教材第 7 章；不要求入门时看完整套课程。
- [Bhat 与 Bernstein：Finite-Time Stability of Continuous Autonomous Systems](https://www.aero.iitb.ac.in/~bhat/siam_fts.pdf)：仅在第 26 讲需要区分有限时间性质时选读。
