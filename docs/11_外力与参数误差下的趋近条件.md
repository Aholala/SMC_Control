# 第 11 讲：外力与参数误差下，哪些趋近结论仍成立

前置内容：[从运动关系推导控制输入](09_从运动关系推导控制输入.md)、[用非负量检查趋近过程](10_用非负量检查趋近过程.md)。本讲只研究扰动怎样改变 s 的变化，以及趋近零所需的条件，不增加算法形式。

## 1. 先定义扰动和抗扰

**扰动是控制模型之外、又会影响实际运动的作用。** 例如有人推动转轴，电机输入没有改变，转动却受到额外影响。

本讲用 d 表示这些作用引起的额外角加速度，单位 rad/s²。这样，第 9 讲的模型变成：

```text
实际角加速度 = b × u + d
```

b 是单位输入引起的角加速度，单位 rad/(s²·A)；u 为电流输入，单位 A。d 是外力等作用换算后的加速度，不能把以 N·m 为单位的外力矩直接填入 d。

**抗扰是受到扰动时仍能维持所要求行为的能力。** 本讲具体检查的行为是：非零的滑模变量 s 是否仍朝零靠近。它不直接等同于位置误差始终为零。

## 2. 先看一个简单数值

滑模变量沿用 `s=ė+ce`：e 为实际角度减目标角度，ė 为误差变化率，c>0 为固定系数。s 的单位为 rad/s，ṡ 为 s 的变化率，单位 rad/s²。

第 9 讲无扰动时，希望实现：

```text
ṡ = -K × s - ε × sign(s)
```

K>0，单位 1/s；ε>0，单位 rad/s²；sign(s) 在正、零、负时分别返回 +1、0、−1。

教学假设 K=1 /s、ε=2 rad/s²。若 s=2 rad/s，原本要求 ṡ=−4 rad/s²；现在额外加入 d=+1 rad/s²，实际 ṡ 变成 −3，仍朝零运动，但速度改变了。

若 s=.5 rad/s，原本 ṡ=−2.5；加入 d=+3 后，实际 ṡ=+.5，此时 s 反而离零更远。因此不能只说“滑模有抗扰能力”，还要说明扰动大小和控制条件。

## 3. 从对象公式重新代回

r̈ 表示目标角加速度。第 9 讲的控制律，即计算电流的公式，不使用未知的 d：

```text
u = [r̈ - c × ė - K × s - ε × sign(s)] / b
```

由误差定义和对象关系：

```text
误差加速度 = b × u + d - r̈
ṡ = 误差加速度 + c × ė
```

将电流公式代回：

```text
ṡ = -K × s - ε × sign(s) + d
```

控制律消去了已知模型项，未知扰动仍留在真实运动中。本节先假定 b 准确、输入能完整执行、测量与目标变化率准确，没有延迟或额外的输出大小限制。

## 4. 用上一讲的非负读数检查

第 10 讲的李雅普诺夫函数，是用于分析运动变化的非负函数。本例取 `V=s²/2`，衡量 s 偏离零的程度；V̇ 是它随时间的变化率：

```text
V̇ = s × ṡ
   = -K × s² - ε × |s| + s × d
```

V 的单位为 rad²/s²，V̇ 的单位为 rad²/s³；|s| 表示 s 不带正负的大小。新出现的 `s×d` 可能为正，也可能为负：扰动可能妨碍趋近，也可能帮助趋近。

**上界是保证某个量不会超过的界限。** 假设在所研究的整个运动过程中都有 `|d|≤D`，其中 D≥0，单位 rad/s²。这里必须有足够依据声明 D，不能用观察到的一个扰动值代替全部时刻的保证。

因为 `s×d≤|s|×|d|≤D×|s|`，得到：

```text
V̇ ≤ -K × s² - (ε-D) × |s|
```

这就是在不知道扰动具体正负时，按最不利方向作出的检查。它允许 d 随时间变化，但必须始终满足已声明的上界和本节对象关系。

## 5. 三种大小关系分别意味着什么

**ε>D：** 非零 s 处，两项合起来严格为负，V 减小。非零分支上，|s| 的减少速率至少为 ε−D；因此在这些理想连续时间前提下，从非零初值首次到达零的时间不晚于 `|s(0)|/(ε-D)`。s(0) 表示开始时的 s。这个条件足以保证所研究的首次趋近过程，但不是所有可能情况的必要条件。

**ε=D：** 因 K>0，仍有 `V̇≤−Ks²=−2KV`，非零 s 仍向零趋近；不过最不利扰动可以刚好抵消符号项，此时只剩 `ṡ=−Ks` 的逐渐衰减，不能保证有限时间到达。

**ε<D：** 上式在 `|s|>(D−ε)/K` 时仍严格为负，但靠近零时不再保证为负。它表示这里的统一保证不足，不能据此声称所有运动都会发散，也不能保证任意扰动下都到零。

例如 K=1、ε=2、恒定 d=+3，且 s>0：

```text
ṡ = -s + 1
```

s=2 时 ṡ=−1，仍向零方向移动；s=.5 时 ṡ=+.5，反而离零更远；s=1 时 ṡ=0。**平衡值指在当前固定条件下能保持不变的值。** 本例 s=1 rad/s 就是一个非零平衡值，正侧运动可以趋向它而不是零。

以下全部为教学假设，保持同一套 K=1 /s、ε=2 rad/s²：

| s / (rad/s) | d / (rad/s²) | 实际 ṡ / (rad/s²) | V̇ / (rad²/s³) |
| ---: | ---: | ---: | ---: |
| +2 | +1 | −3 | −6 |
| −2 | −1 | +3 | −6 |
| +.5 | +3 | +.5 | +.25 |
| −.5 | −3 | −.5 | +.25 |
| +2 | +3 | −1 | −2 |
| −2 | −3 | +1 | −2 |
| +1 | +3 | 0 | 0 |
| −1 | −3 | 0 | 0 |

## 6. 到零以后，不能直接照搬上一讲的保持约定

本讲仍定义 sign(0)=0。若此刻 s=0、d=1，直接代入实际关系就有 ṡ=1；所以不能同时用这个单值公式，又宣称此后永远保持 s=0。

虽然此刻 `V̇=s×ṡ=0`，它也不证明以后 V 始终为零。理想不连续控制怎样在零处抵抗持续扰动，需要进一步规定零处的运动含义；本讲不引入这一独立主题。

因此本讲**只在非零分支研究首次趋近，达到零的曲线在那里停止**，不把后面的 s 人为改成零，也不宣称已验证有扰动时始终保持滑模面。第 8～10 讲在无扰动下使用的保持零约定不直接延伸到本讲。

## 7. 参数误差怎样进入同一检查

**参数误差是模型中使用的参数与真实值之间的差异。** 这里只讨论输入增益 b 的误差。令 b0 为控制器计算时使用的已知非零值，b_actual 为对象的真实值，d_external 为外力等造成的额外角加速度。

```text
实际角加速度 = b_actual × u + d_external
             = b0 × u + [(b_actual-b0) × u + d_external]
```

把方括号内的总差额记为 Δ，单位仍为 rad/s²：

```text
Δ = (b_actual-b0) × u + d_external
ṡ = -K × s - ε × sign(s) + Δ
```

若能在研究的全过程保证 `|Δ|≤D`，前面用 d 推出的不等式就能使用。注意 Δ 包含 u，它一般不是一个与控制输入无关的固定数；不能因为某个时刻误差很小，就断言全过程上界也小。输入方向弄反也不在“任意参数误差都能抵消”的保证内。

一个当前时刻的代回例子：c=.5 /s、e=1 rad、ė=0、r̈=0，使用 b0=5 rad/(s²·A)，仍有 s=.5、u=−.5 A。若实际 b_actual=4、d_external=1，则 Δ=1.5，模型产生 ṡ=−1，等于 `−2.5+1.5`。这只核对一个时刻，不证明全过程 Δ≤1.5。
