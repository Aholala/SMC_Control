# 第 16 讲：目标也在运动时，变化率从哪里来

前置内容：[误差与误差变化率](02_误差与误差变化率.md)、[计算间隔与差分](04_计算间隔与差分.md)、[原参考代码与公式逐句对照](14_原参考代码与公式逐句对照.md)、[初始化复位与旧输出](15_初始化复位与旧输出.md)。本讲只研究目标变化率的来源和使用时刻，不推进对象运动。

## 1. 先定义目标变化率

**目标角速度是目标角度随时间的变化率；目标角加速度是目标角速度随时间的变化率。** 它们描述希望对象怎样运动，不是对象已经测得的实际速度或加速度。

用 r 表示目标角度，ṙ 表示目标角速度，r̈ 表示目标角加速度。角度用度、时间用秒时，它们的单位分别为 °、°/s、°/s²。

本讲讨论两种来源：

- 已知生成目标的公式，直接给出相应的速度和加速度。
- 只有相邻时刻的目标角度，用它们的差和时间间隔近似变化率。

第二种叫**差分近似**，即用有限时间内的数值差近似瞬时变化率。第 14 讲已经区分角度差和除以时间后的变化率近似；本讲进一步检查近似值属于哪次采样。

## 2. 先用一个可以手算的目标

取教学目标：以秒计的时间数值为 t，以度计的目标角度数值为 t³。立方 t³ 表示 t×t×t。

已知幂次求变化率的规则：t 的 n 次方随 t 的变化率为 n×t 的 n−1 次方；这里 n 是正整数。因此：

```text
目标角度数值：   r(t) = t³
目标角速度数值： ṙ(t) = 3t²
目标角加速度：   r̈(t) = 6t
```

三个量仍分别使用 °、°/s、°/s²。没有把三种单位混成一种。在 t=1 s 时，直接得到 r=1°、ṙ=3°/s、r̈=6°/s²。

这是人为给定的教学目标公式，不是从真实电机参数或测量数据猜出的目标变化率。

## 3. 什么是本拍与上一拍

一拍表示一次计算。下标 k 表示当前这次，k−1 表示上一次，k−2 表示再前一次；对应时刻为 t_k、t_(k−1)、t_(k−2)。本节假定相邻间隔都是 h 秒，且 h>0。

v_hat_k 表示用本次和上次目标角度算出的速度近似值，a_hat_k 表示用本次及前两次目标角度算出的加速度近似值：

```text
v_hat_k = (r_k-r_(k-1)) / h
a_hat_k = (r_k-2r_(k-1)+r_(k-2)) / h²
```

v_hat_(k−1) 则是上一次已算出的速度近似值：

```text
v_hat_(k-1) = (r_(k-1)-r_(k-2)) / h
```

“本拍差分”表示它使用了刚收到的 r_k，不表示它已经是当前瞬时速度的准确值；第一条仍然是最近一段时间的平均速度。

例如在 t_k=1 s、h=.1 s 时：

| 时刻 / s | 目标角度 / ° |
| ---: | ---: |
| 1 | 1 |
| .9 | .729 |
| .8 | .512 |

于是：

```text
v_hat_k     = (1-.729)/.1 = 2.71 °/s
v_hat_(k-1) = (.729-.512)/.1 = 2.17 °/s
a_hat_k     = (1-2×.729+.512)/.01 = 5.4 °/s²
```

当前准确目标速度为 3°/s；即使都是单位正确的近似值，2.71 与 2.17 也不能不加说明地互换。

## 4. 单位正确后，近似误差仍然存在

把 t³ 代入上面的差分式并展开，在本讲固定单位下有：

```text
v_hat_k     = 3t² - 3th + h²
v_hat_(k-1) = 3t² - 9th + 7h²
a_hat_k     = 6(t-h)
```

可以看到，本例 a_hat_k 恰好等于 t−h 时的准确目标加速度，不等于 t 时的 6t。它使用了本拍数据，也仍会与当前准确变化率有差别。

同样在 t=1 s、h=.1 s，比较几个简单目标可帮助核对：

| 目标角度数值公式 | 准确速度 | 本拍速度差分 | 上一拍速度差分 | 准确加速度 | 本拍加速度差分 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 固定为 2 | 0 | 0 | 0 | 0 | 0 |
| 2t | 2 | 2 | 2 | 0 | 0 |
| t² | 2 | 1.9 | 1.7 | 2 | 2 |
| t³ | 3 | 2.71 | 2.17 | 6 | 5.4 |

表中速度单位均为 °/s，加速度均为 °/s²。匀速目标下，本拍和旧拍速度差分相同，不能靠这一种输入检查出使用旧拍的问题；t³ 让速度、加速度都变化，差别才更清楚。

本讲公式以前后间隔相同为前提，没有将其推广到变化的采样间隔。实验也不加入测量噪声，不把缩短间隔当作任意情况下误差都会减小的保证。

## 5. 哪个速度用来计算本次误差变化率

θ̇_k 是本次实际角速度测量。**误差变化率是实际速度减目标速度**，记为 ė；e=θ−r 是位置误差。若采用本拍速度近似，则：

```text
ė_estimated = θ̇_k - v_hat_k
```

若在更新 v_hat_k 之前就先计算误差变化率，则可能实际用了：

```text
ė_mixed = θ̇_k - v_hat_(k-1)
```

这里的 mixed 表示把当前测量与旧拍的目标速度近似放在一起。对于 t=1 s、θ̇=3°/s 的例子，准确误差变化率为 0，本拍差分得到 .29°/s，旧拍差分则得到 .83°/s。

如果本节采用差分方案，一种明确的计算次序是：

```text
先用本次目标与上次目标算出本次速度近似；
再用本次速度近似减旧速度近似，除以 h，得到本次加速度近似；
用本次测量速度减本次目标速度近似，计算误差变化率；
本次需要的量都算完后，保存历史供下一拍使用。
```

这是为说明时序而写的独立对照，没有改写原参考或给生产库新增差分历史。首次历史不足的问题仍需遵守第 15 讲的初始化约定，本实验提前提供三次目标值，没有把缺失历史默认为零。

## 6. 对控制电流有什么具体影响

沿用当前普通位置公式。c 是组合位置误差的正系数，K 是乘滑模变量的系数；两者单位 1/s。滑模变量为 s=ė+ce，单位 °/s。ε 的单位为 °/s²，b 为每安培引起的角加速度，单位 °/(s²·A)。φ>0 与 s 同单位，决定零附近连续处理的范围。

饱和函数 sat(x) 在 −1≤x≤1 时返回 x，范围外返回相应的 ±1。请求电流为：

```text
u_request = [r̈ - c × ė - K × s - ε × sat(s/φ)] / b
```

教学参数 b=5、c=.5、K=1、ε=2、φ=1，单位如上。固定 t=1 s、测量角度 θ=2°、测量角速度 θ̇=3°/s，比较三组目标变化率输入：

| 输入方法 | 提供的目标速度 / (°/s) | 提供的目标加速度 / (°/s²) | 算出的 ė / (°/s) | s / (°/s) | 请求电流 / A |
| --- | ---: | ---: | ---: | ---: | ---: |
| 准确变化率 | 3 | 6 | 0 | .5 | .9 |
| 本拍速度差分、本拍加速度差分 | 2.71 | 5.4 | .29 | .79 | .577 |
| 旧拍速度差分、本拍加速度差分 | 2.17 | 5.4 | .83 | 1.33 | .331 |

第三组只比第二组多换成旧拍速度近似，其他当前输入相同，因此其额外差异能归因于这个时序改变。三组都调用相同生产公式，不用不同控制器来比较。

当前库的 target_rate 和 target_acceleration 是调用方明确提供的值，不会自动从目标历史推测。填零表示调用方给了零变化率；目标正在运动时，不能把“没有提供”解释成库会替你求导，也不能用实际测量速度冒充目标速度，否则会改变误差变化率的定义。

## 7. 源码的实际顺序

- 参考 A 的 [slidingmodec.cpp](../SMC_Controller/SMC/slidingmodec.cpp) 第 12～13 行先更新本次 dref，第 21～22 行再使用它。它用了本次角度差，但仍有第 14 讲的时间单位问题。
- 参考 C 的 [slidingmodec.cpp](../smc/SMC/slidingmodec.cpp) 第 15 行先由旧 target_dot 计算 error_dot，第 17 行才更新本次 target_dot；后续控制仍使用先前得到的 error_dot。因此除了没有除以时间，还存在使用旧拍目标差的问题。
- 本讲第三组是**在单位一致的同一普通位置公式中单独改变速度输入时刻**。它不是参考 C 全部公式的运行结果，也没有复现其其他分支。
- 当前 [ALG_SMC.cpp](../main/ALG_SMC.cpp) 第 79、104 行直接使用输入的 target_rate、target_acceleration；[ALG_SMC.hpp](../main/ALG_SMC.hpp) 第 23～25 行说明这两个零值不是自动估计开关。
- 相邻差与变化率近似的基本关系核对 [MathWorks 官方 diff 文档](https://www.mathworks.com/help/matlab/ref/double.diff.html)。本讲直接写明差分算式，不需要符号求导工具箱；t³ 的推导与时序对照独立给出。
