# 第 13 讲：输出做不到公式要求时会怎样

前置内容：[从运动关系推导控制输入](09_从运动关系推导控制输入.md)、[用非负量检查趋近过程](10_用非负量检查趋近过程.md)、[抖振与零附近的连续处理](12_抖振与零附近的连续处理.md)。本讲只检查输出限制怎样改变当前时刻的运动关系，不展开完整位置运动实验。

## 1. 先定义输出限幅

**输出限幅是将控制器算出的输出约束在指定上下限内的操作。** 请求低于下限，就使用下限；高于上限，就使用上限；在范围内则保持不变。

用 u_request 表示公式原本要求的电流，u_out 表示限幅后交给对象的电流，单位均为 A。下限为 u_min，上限为 u_max，要求 u_min≤u_max。

例如请求 −.5 A，而允许范围为 −.2～+.2 A，限幅后只能给 −.2 A。**请求电流和执行电流是两个需要分别记录的量。** 本讲对象假设准确执行 u_out，软件给出的数值不被当作真实电流测量结果。

min(a,b) 表示取较小值，max(a,b) 表示取较大值，因此也可写为：

```text
u_out = max(u_min, min(u_max, u_request))
```

上下限可以不对称；本讲主要使用对称教学范围 −L～+L，其中 L≥0 是允许的电流大小。所有数值都是教学假设，不是某台机器人的设备限制。

## 2. 与上一讲的 sat 分开

第 12 讲的 sat(x) 是把没有单位的输入约束在 −1～+1 内的函数：输入位于范围内时返回自身，范围外返回相应边界。

滑模变量仍为 `s=ė+ce`。e 是实际角度减目标角度，单位 rad；ė 是误差变化率，单位 rad/s；c>0，单位 1/s；s 的单位为 rad/s。φ>0，单位与 s 相同，规定零附近连续处理的范围。

`sat(s/φ)` 只参与完整控制公式中的一项；最终电流限幅则作用于整个公式的结果。即使 sat 已经返回 ±1，整个请求电流仍可能超过电流上限。

下面沿用当前库的普通位置公式：

```text
u_request = [r̈ - c × ė - K × s - ε × sat(s/φ)] / b
```

r̈ 是目标角加速度，单位 rad/s²；K>0，单位 1/s；ε>0，单位 rad/s²；b 是每安培引起的角加速度，单位 rad/(s²·A)，已知且非零。输出限幅不修改这些参数或原请求值。

## 3. 一个先能手算的例子

教学假设 b=5、c=.5、K=1、ε=2、φ=.1，单位如上一节。当前目标静止，e=1 rad、ė=0、r̈=0：

```text
s = 0 + .5×1 = .5 rad/s
sat(s/φ) = sat(5) = 1
u_request = [0 - 0 - .5 - 2] / 5 = -.5 A
```

没有额外扰动，模型为 `实际角加速度=b×u_out`。若允许 −1～+1 A，请求可以完整执行，实际角加速度是 −2.5 rad/s²；若只能给 −.2～+.2 A，实际角加速度只有 −1 rad/s²。

第 9 讲已有 `ṡ=实际角加速度−r̈+cė`，ṡ 表示 s 的时间变化率。本例后两项为零，因此实际 ṡ 从原来要求的 −2.5 变成 −1。它仍朝零方向变化，但已不是原公式规定的变化率。

## 4. 限幅后，真实变化率多出什么

用 d 表示额外扰动引起的角加速度，单位 rad/s²。假定模型准确、数据对应同一时刻、电流立即执行，则：

```text
实际角加速度 = b × u_out + d
ṡ_actual = b × u_out + d - r̈ + c × ė
```

ṡ_desired 表示不考虑限幅、也不含未知扰动时，控制公式希望实现的变化率：

```text
ṡ_desired = -K × s - ε × sat(s/φ)
```

**限幅差额是执行值减请求值**，记为 Δu，单位 A：

```text
Δu = u_out - u_request
```

把 `u_out=u_request+Δu` 代入对象关系，再代回请求公式，可以消去已知项，得到：

```text
ṡ_actual = ṡ_desired + b × Δu + d
```

`b×Δu` 是请求没有完整执行所造成的角加速度差额。未发生限幅且 d=0 时，这两种变化率才相同。b 也可能为负，不能只根据 Δu 的正负判断实际影响，必须保留 b 一起计算。

第 10 讲用 `V=s²/2` 衡量 s 偏离零的程度，V̇ 是它随时间的变化率。由于 `V̇=s×ṡ_actual`：

```text
V̇ = -K × s² - ε × s × sat(s/φ) + s × b × Δu + s × d
```

无扰动、未限幅时，前两项在非零 s 处为负；发生限幅后，新增项可能抵消它们。不能直接继续使用未限幅时的趋近结论。

## 5. 限幅不一定只是让趋近变慢

先保持 e=1、r̈=0，改变当前误差变化率为 ė=3 rad/s，仍使用第 3 节参数，限幅为 ±.2 A：

```text
s = 3 + .5×1 = 3.5 rad/s
ṡ_desired = -3.5 - 2 = -5.5 rad/s²
u_request = [0 - .5×3 - 3.5 - 2] / 5 = -1.4 A
u_out = -.2 A
ṡ_actual = 5×(-.2) + .5×3 = +.5 rad/s²
V̇ = 3.5×.5 = +1.75 rad²/s³
```

此刻 s 为正，实际还在增加，V 也增加。虽然请求电流方向正确，但受限电流不足以让 s 在这个状态下减小。这是一个当前时刻的反例，不能从这一点断言整个运动以后一定发散。

下表为实验的七个手算场景，参数 c=.5、K=1、ε=2、φ=.1 不变，额外扰动均为零。

| 场景 | b / [rad/(s²·A)] | e / rad | ė / (rad/s) | r̈ / (rad/s²) | 电流范围 / A |
| --- | ---: | ---: | ---: | ---: | --- |
| A：请求完整执行 | +5 | 1 | 0 | 0 | −1～+1 |
| B：受限后仍趋近 | +5 | 1 | 0 | 0 | −.2～+.2 |
| C：B 的反向状态 | +5 | −1 | 0 | 0 | −.2～+.2 |
| D：当前变化率变为零 | +5 | 1 | 2 | 0 | −.2～+.2 |
| E：受限后偏离 | +5 | 1 | 3 | 0 | −.2～+.2 |
| F：目标正在加速 | +5 | 0 | 0 | 2 | −.2～+.2 |
| G：相反的输入增益 | −5 | 1 | 0 | 0 | −.2～+.2 |

| 场景 | u_request / A | u_out / A | ṡ_desired / (rad/s²) | ṡ_actual / (rad/s²) |
| --- | ---: | ---: | ---: | ---: |
| A | −.5 | −.5 | −2.5 | −2.5 |
| B | −.5 | −.2 | −2.5 | −1 |
| C | +.5 | +.2 | +2.5 | +1 |
| D | −1.1 | −.2 | −4.5 | 0 |
| E | −1.4 | −.2 | −5.5 | +.5 |
| F | +.4 | +.2 | 0 | −1 |
| G | +.5 | +.2 | −2.5 | −1 |

F 的位置和速度当前都与目标匹配，s=0，但目标加速度 2 rad/s² 超过该输入范围最多能产生的 +1 rad/s²；因此不能继续保持原来的匹配关系。此刻 V̇=0 也不能证明以后仍保持 V=0。

限幅也会改变第 11 讲的抗扰前提。例如 B 再加入 d=1.5 rad/s²，实际 ṡ=−1+1.5=+.5，V̇=+.25。即使这个额外扰动小于 ε=2，也不能忽略限幅造成的 `bΔu=1.5`。未知扰动上界本身不足以覆盖新的执行差额。

## 6. 只改变允许电流，检查同一个状态

固定 E 的当前状态，允许范围改为 −L～+L，L 从 0 增至 1.5 A；其请求始终是 −1.4 A。

L≤1.4 A 时，u_out=−L，因此：

```text
ṡ_actual = -5L + 1.5
```

L<.3 A 时实际 ṡ 为正，L=.3 A 时为零，L>.3 A 后才为负；当 L≥1.4 A，请求可以完整执行，才恢复期望的 −5.5 rad/s²。

所以“此刻朝零运动”和“完整实现期望变化率”是两个不同条件。这是在同一状态下比较不同允许范围，不是电流限幅随时间变化的轨迹，也不是实际项目的选值建议。
