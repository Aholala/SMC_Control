# 第24讲：位置误差累计与持续外力

前置内容：[外力下的趋近条件](11_外力与参数误差下的趋近条件.md)、[输出限幅](13_输出限幅怎样改变趋近关系.md)、[速度误差累计](23_速度误差累计与速度控制.md)。本讲把累计思想用于位置控制，使用现有IntegralPosition；不增加累计限幅或冻结。

## 1. 位置误差累计是什么

位置误差e是实际角度θ减目标角度r，单位rad。**位置误差累计值z，是把位置误差乘这段时间，再逐段相加得到的状态**，单位rad·s。

这与第23讲不同：那一讲累计速度误差，单位rad；本讲累计位置误差，单位rad·s。例如e=.5rad持续.5s，本段贡献为.25rad·s；再持续.5s，累计为.5rad·s。

当前误差变成0，只意味着这一段不再增加累计，不会自动清除过去的值。复位才会清零本类的累计。

## 2. 怎样加入位置关系

记v为实际角速度减目标角速度，即e的变化率。滑模变量是用于规定误差关系的组合量，当前选择：

```text
z_new = z_old + e*dt
s = v + c1*e + c2*z_new
```

c1单位1/s，c2单位1/s²，因此三项都用rad/s。参数c1、c2来自使用项目；本讲只是教学数值，不能从两个参数数值相等推断它们单位相同。

连续时间下z_dot=e。对象仍为角加速度=b*u+d，d表示外力等折算的加速度；目标加速度为r_ddot。先忽略d，对s求时间变化率：

```text
s_dot = b*u - r_ddot + c1*v + c2*e
```

沿用此前趋近规则 `s_dot=-K*s-epsilon*sat(s/phi)`，解得：

```text
request = (r_ddot-c1*v-c2*e-K*s-epsilon*sat(s/phi))/b
```

sat是第12讲的连续饱和函数。注意新增的−c2*e：它来自累计项求变化率，不能只把累计加进s而遗漏这一项。

## 3. 先核对手算与复位

教学参数b=2、c1=2、c2=1、K=3、epsilon=4、phi=2，输出±3A。初始z=0，e=.5rad、v=0、dt=.5s、目标加速度0：

```text
z=.25rad·s
s=0+2*.5+1*.25=1.25rad/s
request=(0-0-.5-3*1.25-4*.625)/2=-3.375A
output=-3A
```

再次使用相同输入时，z=.5、s=1.5，请求−4A，输出仍−3A。请求不同，最终电流相同；累计没有因为输出受限而冻结。

实验还检查反向误差、目标加速度非零、带速度误差、两次复位，共八个连续明确点。复位保留配置和输出范围，清累计与诊断；外部command仍由调用方持有。

## 4. 持续外力下会观察到什么

用同一个教学对象比较普通位置与位置累计：b=3，初始角度−.2rad、速度0，目标.5rad，dt=.001s，总时长8s，输出±4A，2s起加入d=.4rad/s²。两者c1=4、K=6、epsilon=2、phi=.25；累计形式另取c2=4/s²。

普通位置控制在这个模型下留下约.00714rad误差。累计形式可以让当前位置误差接近0，同时保留一个非零累计值来产生抵消外力的电流。

这句话有明确条件：目标静止、末端速度为0、输出能够执行、对象匹配，并处于连续处理区。此时若e=0，s=c2*z，平衡需要：

```text
u=-d/b
z=d/[c2*(K+epsilon/phi)]
```

本例z约.007142857rad·s。它不是位置误差；不能因z非零就判断角度还没跟上。

另一个案例把输出限制改为±.2A。它仍执行同一累计规则，8s末误差约2.62rad、累计约12.29rad·s，没有收敛。保留这个结果用于说明输出约束的影响，不把参数范围或累计冻结偷偷加入算法。第四个案例检查暂停、清累计与当前物理状态重启。
