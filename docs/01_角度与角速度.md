# 第 01 讲：角度与角速度

这一讲只回答：角度和角速度分别是什么，它们怎样联系。

先修要求：会用正负数做加减乘除。不要求已经学过微积分或控制算法。本讲不使用控制器，不计算电机电流，不引入误差和滑模公式。

## 1. 角度是什么

在本讲只研究绕一根轴转动的情况下，**角度描述物体相对于选定零方向转到了哪里**。

以云台的水平转轴为例：把朝正前方规定为 0°，从上往下看，规定逆时针为正方向。那么相对于正前方逆时针转到 10° 的位置，可以写成 +10°；顺时针转到 10° 的位置，可以写成 −10°。

正方向是本讲的约定，真实项目必须统一自己的约定。这里的“度”是角度单位，一整圈是 360°。

角度告诉我们此时的位置。云台处于 10° 时，它可能停着，也可能正在向任一方向转动；仅有角度这个数值还不能区分这些情况。

## 2. 角速度是什么

**角速度描述角度变化的快慢和方向。** 本讲用“度每秒”作为单位，写作 °/s。

当角速度保持 +30°/s 时，每过 1 s，角度增加 30°；保持 −30°/s 时，每过 1 s，角度减少 30°。0°/s 表示角度没有在变化，不表示当前角度为 0°。

例如，角度为 10°、角速度为 0°/s，表示“停在 10° 的位置”；角度为 10°、角速度为 +30°/s，表示“此时在 10°，并沿正方向转动”。

不要把角速度的数值和位置直接相加：10° 与 30°/s 不是同一类量。需要先乘以时间，才得到这段时间里转过的角度。

## 3. 恒定角速度下怎样计算角度

先解释接下来使用的符号：

- `θ`，读作 theta，表示当前角度，单位 °。
- `θ0` 表示开始观察时的初始角度，单位 °。
- `ω`，读作 omega，表示角速度，单位 °/s。
- `t` 表示从开始观察到现在已经过的时间，单位 s。

本讲的前提是：角速度从观察开始一直保持不变，角度也使用同一个零方向和正方向。

先用文字表达关系：

```text
这段时间转过的角度 = 角速度 × 已经过的时间
当前角度 = 初始角度 + 这段时间转过的角度
```

写成公式就是：

```text
θ = θ0 + ω × t
```

例子：初始角度为 10°，保持 +30°/s，观察 2 s：

```text
转过的角度 = 30°/s × 2 s = 60°
当前角度   = 10° + 60° = 70°
```

这里的 60° 是这段时间里位置的变化，70° 才是最后的位置。如果角速度在过程中发生变化，不能直接拿某一时刻的角速度乘整个时长；本讲实验刻意采用不变的角速度。

## 4. MATLAB 实验

运行入口：[run_lesson.m](../matlab/教学/第01讲_角度与角速度/run_lesson.m)。直接运行整个文件，或运行根目录 [start.m](../start.m)，默认 `mode='教学'、number=1`。

只依赖 MATLAB，不需要 Simulink、C++ 编译器或额外工具箱。全部参数为教学假设，不是三份开源里的实机参数。

| 参数 | 值和单位 | 含义 |
| --- | --- | --- |
| `initial_angle_deg` | 10° | 三个场景的共同起点 |
| `angular_rates_deg_s` | +30、0、−30 °/s | 三种分别保持不变的角速度 |
| `duration_s` | 2 s | 观察时长 |
| `plot_step_s` | .02 s | 绘图取点间隔；本讲直接用公式算角度，不用它近似运动 |

预期结果：

| 场景 | 2 s 后的角度 | 图上应该看到什么 |
| --- | ---: | --- |
| +30°/s | 70° | 角度向上增加，角速度是一条水平线 |
| 0°/s | 10° | 角度保持在 10°，角速度保持为零 |
| −30°/s | −50° | 角度向下减少，角速度是另一条水平线 |

程序自动检查末值与手算是否一致、共同起点是否正确、静止场景是否不动、正负速度方向是否正确。输出在 `build/教学/第01讲_角度与角速度/`：PNG、可重新打开的 FIG、CSV、MAT 参数与数据，以及 JSON 运行报告。

CSV 第一列为时间，接下来三列是正向/静止/反向角度，最后三列是对应角速度。列名中的 `_deg` 表示度，`_deg_s` 表示度每秒。
