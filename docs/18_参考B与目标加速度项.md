# 第 18 讲：与参考 B 的普通位置公式相比，差异来自哪里

前置内容：[从运动关系推导控制输入](09_从运动关系推导控制输入.md)、[输出限幅怎样改变趋近关系](13_输出限幅怎样改变趋近关系.md)、[最小普通位置闭环](17_最小普通位置闭环.md)。本讲只比较目标加速度项的保留与省略，不增加生产算法分支。

## 1. 先定义这次比较的量

**目标加速度是目标角速度随时间的变化率**，记为 r̈，单位 rad/s²。它与实际角加速度 θ̈ 不同：前者描述希望怎样运动，后者描述对象实际怎样运动。

r 是目标角度，θ 是实际角度，单位均为 rad；ṙ、θ̇ 分别是目标与实际角速度，单位 rad/s。误差采用 e=θ−r，误差变化率为 ė=θ̇−ṙ。

**本讲的完整式**是包含 r̈ 的普通位置电流公式；**省略式**是其他项相同、只不加 r̈ 的公式。比较这两条表达式之前，必须让它们使用相同的变量含义和单位。

## 2. 参考 B 实际写了什么

EXPONENT 是参考 B 中普通位置控制分支的名称。[Sliding.cpp](../Sliding/code/Sliding.cpp) 第 144～147 行先计算 s，再计算电流。以 `//` 开头的行是注释，不参与运行：

```cpp
s = c * position_error + velocity_error;
// 包含目标二次变化率的写法留在注释中。
u = J * (-c * velocity_error - K * s - epsilon * Sat(s));
```

上面将成员访问写短，便于看清表达式；实际原行及完整成员名仍以来源文件为准。未被注释的第 147 行没有 `tar_differential_second`，第 146 行的注释表达式则包含它。

配套 [SMC_Doc.tex](../Sliding/Documentation/SMC_Doc.tex) 第 105、129～132 行的推导包含目标加速度，并明确说明代码去除了该项。因此这里的差别能从文档与实际执行语句直接核对，不根据分支名字猜测。

参考 B 的位置 ErrorUpdate 第 72～82 行虽然算出了目标一、二次差分，但“保存了某个量”和“普通位置输出使用了它”是两件事。

## 3. 先统一其余量，避免同时比较多个差别

本讲使用对象关系 `θ̈=b×u`，u 的单位为 A；b 是每安培引起的角加速度，单位 rad/(s²·A)，已知且非零。参考 B 文档第 63～65 行将电机产生力矩的比例并入名为 J 的系数，模型写成 θ̈=u/J。因此在相同单位和方向下，本讲对应 b=1/J。

滑模变量为 s=ė+ce，单位 rad/s；c、K 的单位为 1/s，ε 的单位为 rad/s²。饱和函数 sat(x) 在 −1≤x≤1 时返回 x，外部返回相应的 ±1；φ>0，与 s 同单位。统一后的两条请求公式为：

```text
s = ė + c × e
u_full = [r̈ - c × ė - K × s - ε × sat(s/φ)] / b
u_omit = [   - c × ė - K × s - ε × sat(s/φ)] / b
```

u_full、u_omit 分别表示完整式和省略式的请求电流。参考 B 的 Sat 会把 s 除以 epsilon，再与 limit 比较；当前库则将切换强度 ε 和宽度 φ 分开。参考还含目标差分、位置误差死区及最终输出限制。若直接换一份完整程序，多个差别可能同时出现。

因此本实验用同一个当前生产库、同一组参数计算两式：完整组提供准确 r̈，省略组只在调用处将 target_acceleration 设为零。其他目标数据、公式、限制和对象保持一致。**这个单位一致的省略组不是参考 B 整个工程的复现**，本讲没有运行原 B 或修改它。

## 4. 在同一个状态点，电流差是多少

保持同一个 e、ė、s 和参数，两条请求式相减，其他项抵消：

```text
u_full - u_omit = r̈ / b
```

这条等式针对最终限幅前的请求电流；发生限幅后，执行值的差不一定仍等于右边。本实验的全部闭环取点均未限幅，避免混入这个影响。

先手算一个位置、速度都已经匹配的时刻：e=0、ė=0，所以 s=0。取本讲教学参数 b=3 rad/(s²·A)，目标正在以 r̈=.4 rad/s² 加速：

```text
完整式：u_full = .4/3 ≈ .133333 A
省略式：u_omit = 0 A
```

完整式让对象产生 .4 rad/s² 的加速度，此刻能跟上目标的加速；省略式在零误差时没有产生这部分输入，实际加速度为零，随后就会出现相对目标的误差。目标角度和速度当前匹配，不代表下一刻仍能匹配。

## 5. 重新代回对象，趋近关系怎样变

ṡ 表示 s 的时间变化率。由第 9 讲的误差和对象关系：

```text
ṡ = c × ė + b × u - r̈
```

假定模型准确、没有额外外力、输入立即完整执行，则完整式得到：

```text
ṡ_full = -K × s - ε × sat(s/φ)
```

省略式则得到：

```text
ṡ_omit = -K × s - ε × sat(s/φ) - r̈
```

目标加速度没有因为输出公式里不写它，就从真实误差变化中消失。它仍通过对象与目标的相对运动进入 s 的变化关系。

当 r̈=0 时，两条输出公式相同，包括目标静止或目标角速度不变的时段。因此只做静止目标或匀速目标实验，无法显示省略该项在加速目标下的差别。

## 6. 省略以后是否就完全不能跟踪

需要看其误差关系。**匀加速目标是目标加速度保持固定的运动目标。** 令这个固定值为 a_r，单位 rad/s²。在 |s|≤φ 内，sat(s/φ)=s/φ，省略式变为：

```text
ṡ = -(K + ε/φ) × s - a_r
```

**相对目标的平衡偏差是误差能保持不变的值**，不是对象停止运动。若 e 保持不变，ė=0，s=ce；若 s 也保持不变，则 ṡ=0。把这两个条件代入，得到：

```text
e_eq = -a_r / [c × (K + ε/φ)]
s_eq = c × e_eq
```

只有 |s_eq|≤φ 时才能用刚才的内部关系。本讲沿用第 17 讲控制参数：b=3、c=4、K=6、ε=2、φ=.25，单位如上；取 a_r=.4：

```text
e_eq = -.4 / [4×(6+2/.25)] ≈ -.007142857 rad
s_eq ≈ -.028571429 rad/s
```

|s_eq| 小于 .25，满足该条件。负位置偏差表示对象落在加速目标后方；当偏差建立后，误差相关项也能产生使对象加速的电流。因此实验可能看到省略组继续跟着目标加速，同时留有非零位置偏差，不能简单说它完全不能运动。

另一方面，两套闭环运行后各自的位置和速度会不同。第 4 节的 `u_full−u_omit=r̈/b` 只适用于**同一个状态点**，不能拿两套不同状态下的实际输出直接相减，再要求其差始终等于 r̈/b。接近平衡时，两组电流反而可能都接近 .4/3 A，但位置误差不同。

上述偏差公式是理想连续关系的预测，实际取点实验还包含固定间隔计算和数字精度，最终逐次核对并报告偏差，不直接把理论值写成实测结果。

## 7. 同一条件下的三个目标案例

全部控制参数、对象及范围都沿用上节：模型 θ̈=3u，电流范围 ±4 A；间隔 .001 s，每个闭环 4 s。没有噪声、外力、目标差分近似或延迟，目标变化率直接按已知公式提供。

| 案例 | 目标角度 / rad | 目标角速度 / (rad/s) | 目标角加速度 / (rad/s²) | 初始对象角度、速度 |
| --- | --- | --- | --- | --- |
| 静止 | 0 | 0 | 0 | 0 rad、0 rad/s |
| 匀速，即角速度固定 | .2t | .2 | 0 | 0 rad、.2 rad/s |
| 匀加速 | .2t² | .4t | .4 | 0 rad、0 rad/s |

t 为以秒计的时间数值。每个案例的两组都从匹配的角度和速度开始；之后各自的真实 C++ 输出推进各自对象，位置误差没有被人为指定为理论偏差。

静止和匀速案例检查两式在 r̈=0 时是否保持相同；匀加速案例检查目标加速度项的差别。这样把公式差异、目标条件和初始误差分开，不以某条曲线更好看就替代解释。

## 8. 当前库采用的公式与来源边界

当前库的普通位置实现依据是本项目[已冻结数学规格](普通位置滑模数学规格.md)中的完整式，含 r̈，并明确使用独立 ε、独立 φ；[ALG_SMC.cpp](../main/ALG_SMC.cpp) 第 104～114 行从 target_acceleration 开始减去各项，再除以 input_gain。

它保留 A/B 的误差与滑模变量结构，但不把 B 实际省略目标加速度的分支、B 的多重用途 epsilon、死区和目标历史直接作为当前库的行为。本讲只把这些具体适配重新核对，没有更换数学规格或生产实现。

参考 B 的推导从 θ̈=u/J 得到乘 J 的电流公式，与第 14 讲参考 A 附件中 θ̈=J×u 的写法不同。两者都用字母 J，不代表模型系数可原数值互抄；应先按对象关系与单位对应到 b 或 1/b。
