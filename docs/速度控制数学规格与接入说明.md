# 速度控制数学规格与接入说明

速度控制是让实际角速度跟随目标角速度。生产库提供 `SMC::Velocity`，位置控制使用 `SMC::Position`，两者仍共用 [ALG_SMC.hpp](../main/ALG_SMC.hpp) 与 [ALG_SMC.cpp](../main/ALG_SMC.cpp)。

当前版本直接累计速度误差，不附加累计限幅、累计冻结或回算策略。运行时仅保留入口状态和最终结果检查。

## 1. 公式和单位

角速度 ω 是角度的时间变化率，目标角速度记为 r；目标角加速度 a_target 是 r 的时间变化率，由调用方显式提供。控制输入 u 在教学中采用电流 A，b 表示单位输入引起的角加速度，d 表示外力等影响折算的角加速度：

```text
omega_dot = b*u + d
e = omega - r
```

**误差累计值 z 是把每段误差乘以经过时间，再逐段相加得到的状态。** 速度误差为 rad/s，乘秒后 z 的单位为 rad。理想连续时间中写为 `z=∫e dt`，其变化率为 `z_dot=e`。

滑模变量是控制公式使用的误差组合量，这里为：

```text
s = e + c*z
```

c 为乘累计值的正系数。连续饱和函数 sat(x) 在 −1≤x≤1 时返回 x，外部返回对应符号的±1；φ 为与 s 同单位的正宽度。K 和 ε 分别控制乘 s 的项和连续切换项：

```text
s_dot = -K*s - epsilon*sat(s/phi)
u_request = (a_target - c*e - K*s - epsilon*sat(s/phi)) / b
output = clamp(u_request, output_min, output_max)
```

clamp 表示把结果限制到上下限内。速度控制不需要实际角度和实际角加速度输入。

Q 表示项目选定的角度单位，U 表示输出单位，时间为秒：

| 参数/输入 | 含义与单位 |
| --- | --- |
| input_gain | b，Q/(s²·U)，有限非零，允许负值 |
| surface_gain | c，1/s，有限且>0 |
| reaching_gain | K，1/s，有限且≥0 |
| switching_gain | ε，Q/s²，有限且≥0；K和ε不能同时为零 |
| boundary_width | φ，Q/s，有限且>0 |
| target、measurement | 目标和实际角速度，Q/s |
| target_acceleration | 目标角加速度，Q/s² |
| dt | 本次累计代表的间隔，s，必须>0 |
| output_min、output_max | 输出范围，U，有限且下限≤上限 |

默认全零参数无效。项目负责单位、方向、时间和有效测量，不由库猜测机器人参数。

## 2. 每次调用只做这些计算

```text
e = measurement - target
new_z = old_z + e*dt
s = e + c*new_z
request = (target_acceleration - c*e - K*s - epsilon*sat(s/phi)) / b
output = clamp(request, output_min, output_max)
```

与参考 B 一致，先累计，再用新累计值计算 s。第一拍也累计一次；重复 Calc 会重复推进累计，不是只读取结果。

运行时不再逐项检查输入、累计增量、各个乘积及每次减法。位置控制只在入口检查是否初始化，结尾检查完整请求是否为有限数；速度控制另外检查 dt>0，并在结尾一并检查请求与新累计是否为有限数。有限数指能用一个有限大小表示的数值。

结果检查通过后提交诊断、累计和外部 command。计算失败仍保持它们原样；初始化/更新时的参数检查及最终输出限幅保留。sat 的分段计算属于原公式，不是额外保护策略。

## 3. 手算例子与调用

教学参数为 `[b,c,K,ε,φ]=[2,2,3,4,2]`，输出±3 A。初始 z=0，目标速度和加速度为0，实际速度.5 rad/s，dt=.5 s：

```text
e=.5
new_z=.25
s=.5+2×.25=1
request=(0-1-3-2)/2=-3 A
output=-3 A，limited=false
```

第二次用相同输入：z=.5、s=1.5，请求−4.25 A，最终输出−3 A。累计仍增长，不因输出受限而被截断或冻结。.5 s仅便于手算，不是实机周期建议。

完整可编译程序见 [velocity_example.cpp](../examples/velocity_example.cpp)。实际项目的接入位置为：

```cpp
SMC::VelocityConfig c;
c.input_gain = project_b;
c.surface_gain = project_c;
c.reaching_gain = project_k;
c.switching_gain = project_epsilon;
c.boundary_width = project_phi;
SMC::Velocity axis;
bool ready = axis.Init(c, project_min, project_max);

SMC::VelocityInput in;
in.target = desired_speed;
in.target_acceleration = desired_acceleration;
in.measurement = measured_speed;
in.dt = elapsed_seconds;
float command = 0;
if (ready && axis.Calc(in, command)) {
    // 使用项目转换并提交本次输出。
} else {
    // 使用项目处理本次失败；command没有被更新。
}
```

`project_*` 是待项目填写的量，不是库的额外接口。速度 Init 已简化为三个参数；累计范围参数及相关设置/查询接口已删除。

## 4. 状态操作

| 接口 | 行为 |
| --- | --- |
| Init(config,min,max) | 安装参数和输出范围，累计清零，清除诊断 |
| SetParameters(config) | 更新参数，保留累计和输出范围，清除诊断 |
| SetLimits(min,max) | 更新输出范围，保留累计和参数，清除诊断 |
| Reset() | 累计清零，保留参数与输出范围，清除诊断 |
| GetErrorIntegral() | 读取当前累计值 |
| GetResult() | 读取最近成功的 error、error_integral、sliding_variable、requested_output、output、limited |

HasResult 表示是否保存着有效的成功诊断，不能替代本次 Calc 返回值。Reset 不改外部 command，也不让物理速度自动归零。不同实例各自保存累计状态，同一实例串行使用。

## 5. 参考与适配

参考 B 的 [SMC_Doc.tex](../Sliding/Documentation/SMC_Doc.tex) 第134～156行及 [Sliding.cpp](../Sliding/code/Sliding.cpp) 第86～103、189～192行使用 `s=e+c×速度误差累计值`。

保留误差符号、先累计后计算和完整目标加速度项；固定周期改为显式 dt，目标差分改为显式目标加速度，整体乘 J 改为除以单位明确的 b，切换强度 ε 与宽度 φ 分开。参考中未启用的累计限制不加入本库；不复制参数缩放旧累计的逻辑。三个原参考均保持只读。

理想模型匹配、无扰动、输出可完整执行时，可由 `s_dot=e_dot+c*e` 代入得到选定趋近关系。离散调用和输出限幅会改变实际过程，不能从理想推导直接断言任意采样周期都稳定。

持续输出受限时累计仍可增长，可能增加后续超调和恢复时间；本库按公式保留这一行为，何时停止、清累计或切换控制由使用项目决定。

- 主机：`tests/verify_host.ps1`，当前共13项测试；位置网格540组、速度网格1620组，另有位置扩展504组公式检查。
- 总验证：[run_checks.m](../matlab/验证/run_checks.m)，同时运行位置和速度检查。
- 速度单独验证：[run_velocity_checks.m](../matlab/验证/run_velocity_checks.m)，4102次序列、六组各8000行闭环。
- 独立应用：[02_速度控制/run_case.m](../matlab/应用方案/02_速度控制/run_case.m)，或 start.m 设置 `mode='应用'、number=2`，scenario=1～6。

MATLAB 按单精度公式和累计规则独立复算，再比较 C++ 结果；另保留双精度累计的结果与差值，不将长期累计的两种精度视为同一递推。闭环对象仍以双精度独立推进，不从 C++ 读取后续测量或控制来生成参考。额外的标志回放使用真实测量，只用于核对限幅标志，独立闭环不依赖它。

六组案例为恒速、变化目标速度、反向b、强输出限幅、暂停复位重启、持续外力。默认教学参数 `[3,4,6,2,.25]`、输出±4 A、初始角度和速度0、dt=.001 s、时长8 s；反向b为−3，强限幅输出±.25 A。暂停案例1 s清累计并暂停，1.5 s以−1 rad/s目标重启；外力案例2 s起d=.4 rad/s²。变化目标为 `.8*sin(.8*t)+.5*cos(.45*t)`，提供其解析目标加速度。

数值允许差沿用 `2×10⁻⁵+2×10⁻⁵×|独立参考|`，没有为这次精简放宽阈值。强限幅案例核对公式、输出范围和对象推进，记录实际末值，不预设其在8 s内收敛；其余恒速案例末值检查2×10⁻⁵ rad/s，变化目标检查2×10⁻⁴ rad/s。

报告与数据位于 `build/验证/速度控制/`，应用输出位于 `build/应用/速度控制/`，记录本次源码摘要。末行7.999 s与推进后的8 s状态分别记录。M4/M7目标编译与主机计算均不代表已完成固件链接或上板验证。

本轮数值记录：取消累计限幅后，±.25 A强限幅案例的累计绝对值峰值约2.668 rad，7.999 s速度误差约−.511 rad/s，未在本次8 s实验内收敛。独立MATLAB与C++仍逐次一致；这里的验证通过表示公式和数据路径通过核对，不表示该限幅工况已达到目标速度。
