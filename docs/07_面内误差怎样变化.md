# 第 07 讲：如果一直满足滑模面关系，误差怎样变化

前置内容：[滑模变量与滑模面](06_滑模变量与滑模面.md)、[计算间隔与差分](04_计算间隔与差分.md)。本讲只研究假设已经始终满足关系时的运动，不计算电流或到达过程。

## 1. 把前提写完整

e 是角度误差，单位 °；ė 是误差随时间的变化率，单位 °/s；c 是固定正系数，单位 1/s。上一讲的滑模变量为 `s=ė+ce`，滑模面由 s=0 的点组成。

现在明确作一个假设：从本讲观察开始，误差就在线上，并且之后始终满足 s=0。因此始终有：

```text
ė = -c × e
```

这比“某一个时刻落在线上”更强。实际控制器能否到达并维持这条关系，需要之后另外推导和验证。

## 2. 先用数字理解它规定了什么

继续取教学假设 c=.5 /s：

| 当前误差 e | 关系要求的当前变化率 ė |
| --- | --- |
| +10° | −5°/s |
| +4° | −2°/s |
| +1° | −.5°/s |
| −10° | +5°/s |
| 0° | 0°/s |

正误差向下减小，负误差向上增加，两者的大小都在靠近零。随着误差变小，所要求的变化率大小也变小。

不能把开始的 −5°/s 保持整个过程，再按匀速直线算出 2 s 后误差为零；那样已经不再满足本节给定的关系。

## 3. 必要的数学名称与指数函数

**微分方程是把未知的时间曲线与它的时间变化率联系起来的方程。** 这里 `ė=−ce` 就是一条微分方程。求它的解，就是找出一条同时满足这个变化率关系和初始误差的时间曲线。

还需要认识一个函数。以 `2³=2×2×2` 为例，2 是底数，3 是指数。负指数表示相应正指数结果的倒数，例如 `2⁻¹=1/2`。**指数函数是固定底数、让指数随输入改变的函数。** 自然指数函数是其中一种，使用约 2.71828 的固定底数，记作 `exp(x)`；x 是输入的纯数，也可以连续变化而不局限于整数。

本讲会用到 `exp(0)=1`、`exp(−1)≈.367879`，以及对任意有限 x，`exp(x)>0`。这里的 exp 是函数名称，与误差符号 e 分开书写。

它还有一条时间变化率性质：当 c 为常数时，`exp(−ct)` 的变化率为 `−c×exp(−ct)`。先理解这句话是在描述函数变化的速度，再用它代回原关系检查。

## 4. 找到并核对时间曲线

令 t 为从观察开始经过的时间，单位 s；e0 是 t=0 时的初始误差，单位 °；e(t) 表示 t 时刻的误差。满足上述关系的曲线为：

```text
e(t) = e0 × exp(-c × t)
```

c 的单位为 1/s，乘 t 后得到纯数，可以作为 exp 的输入。

可以分两步核对：

1. 初始时刻 t=0，exp(0)=1，所以 e(0)=e0，满足初始条件。
2. 用上一节说明的变化率性质，e(t) 的变化率为 `−c×e0×exp(−ct)`，正好就是 `−c×e(t)`，满足原方程。

**指数衰减是每经过相同时间，数值大小乘以同一个大于零、小于一的比例。** 例如 c=.5 /s、e0=10° 时，每过 2 s 都乘 `exp(−.5×2)=exp(−1)≈.367879`：

| 时间 | 准确误差，约为 |
| --- | ---: |
| 0 s | 10° |
| 2 s | 3.678794° |
| 4 s | 1.353353° |
| 6 s | .497871° |
| 8 s | .183156° |

每次留下相同的比例，而不是每次减少相同的度数。这就是本例的时间曲线逐渐变缓的原因。负初始误差也按同一比例减小其大小，零初始误差则保持零。

对于固定初值，c 越大，相同时间内留下的比例越小。这是当前理想关系的数学性质，不作为实际机器上无限增大 c 的整定建议。

## 5. 越来越接近零，不等于有限时刻精确到零

**收敛到零是随着时间继续增长，误差可以靠近零到任意小的程度。** 上述指数衰减具有这种性质。

但若 e0 不为零，有限 t 下 exp(−ct) 始终为正，所以这条理想数学曲线在任何有限时刻仍保留非零误差；只有 e0=0 的例子从开始就为零。

“有限时间精确到零”指在某个有限时刻误差已经等于零。它与这里越来越接近零的性质不同。图上看起来贴近零线、显示位数把小数写成零，都不能代替这个数学区别。本讲只讨论这条理想曲线，不推广到其他公式或真实电机。

## 6. 与上一讲的相平面怎样对应

对每个准确误差 e(t)，取对应变化率 `ė(t)=−c×e(t)`。这样每个时刻都满足 s=0，在相平面里始终位于同一条直线上。

当 e0=10° 时，从 `(10,−5)` 出发向原点靠近；当 e0=−10° 时，从 `(−10,5)` 出发向原点靠近。e0=0 的误差点保持原点。

上一讲只画了零值关系，这一讲在“关系始终成立”的假设下给这些点加上了时间顺序。仍没有模拟从线外到线上的过程，也没有计算所需控制电流。

## 7. MATLAB：准确关系与逐次更新分开

运行 [run_lesson.m](../matlab/教学/第07讲_面内误差怎样变化/run_lesson.m)，或在根目录 [start.m](../start.m) 设置 `mode='教学'、number=7`。仅需 MATLAB，不需要 C++、Simulink 或其他工具箱。

全部参数为教学假设：c=.5 /s，初始误差 +10/−10/0°，观察 8 s；准确曲线取点间隔 .02 s，只用于绘图。

实验第一部分直接用上述准确关系画误差时间曲线与相平面轨迹。第二部分从 +10° 开始，分别以 .2/.1/.02 s 的间隔，使用第 4 讲的起点变化率更新：

```text
当前变化率 = -c × 当前误差
下一次误差 ≈ 当前误差 + 当前变化率 × dt
```

这是数值近似。区间起点满足关系，不代表在整个区间里把这个变化率保持不变时，也能始终精确满足关系。因此近似数据与准确的面内曲线分别命名、保存和比较。

预期观察：正负准确曲线都趋近零；准确相平面轨迹始终在线上；每 2 s 的缩小比例相同；三种近似的差异在本例中随间隔减小而减小。所选间隔不代表任意间隔、任意实际控制器都具有相同性质。

程序核对初始值、准确曲线的 s=0、正负号、误差大小减小、固定时刻参考值、固定时长的比例，以及独立逐次计算与准确解的差异。输出在 `build/教学/第07讲_面内误差怎样变化/`，保留 PNG、FIG、准确曲线 CSV、三份逐次计算 CSV、MAT 参数数据、JSON 报告。

CSV 中 `exact` 是准确关系直接算出的值，`updated` 是逐次计算值，`difference` 是后者减去前者；`positive/negative/zero` 对应三个初始误差，`_deg` 为度，`_deg_s` 为度每秒。
