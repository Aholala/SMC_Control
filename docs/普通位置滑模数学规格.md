# 普通位置滑模数学规格（首版）

这是库的实现规格，不是按学习顺序展开的讲义。来源为参考 A/B 普通位置公式的独立推导；差异见[来源核查](参考核查与来源说明.md)。

## 1. 输入、模型和单位

角度是转动位置，记为 `θ`；角速度是角度随时间的变化率，记为 `ω`；角加速度是角速度的变化率。上方一个点表示一次时间变化率，两个点表示二次变化率。

目标角度、目标角速度、目标角加速度分别记为 `r、r_dot、r_ddot`，必须由调用方提供并对应同一计算时刻。测量值为 `θ、ω`。

控制输入 `u` 是交给执行端的数值，单位可为电流、力矩或明确映射的命令单位。输入增益 `b` 表示单位输入引起的角加速度。对象假设为：

```text
theta_ddot = b * u + d
```

`d` 是未建模影响引起的角加速度，包括外力等折算后的作用，不直接等同力矩。`b` 非零且允许负值，方向由项目确认。

用 `Q` 表示选定角度单位，`U` 表示选定输出单位，时间为秒：

| 量 | 单位 |
| --- | --- |
| `θ、r、e` | Q |
| `ω、r_dot、error_rate、s、phi` | Q/s |
| `r_ddot、d、epsilon` | Q/s² |
| `c、k` | 1/s |
| `b` | Q/(s²·U) |
| `u、output_min、output_max` | U |

当 Q 为弧度、U 为电流 A 时，物理惯量、转矩常数、减速比和测量坐标共同决定 b；库不猜测这些参数。换成度或命令计数后，必须一起换算相关系数。

## 2. 公式和参数域

误差采用测量减目标，误差变化率采用对应速度之差：

```text
e = theta - r
error_rate = omega - r_dot
```

滑模变量 `s` 是一个由误差组成的标量；滑模面是使该量为零的状态集合。首版选：

```text
s = error_rate + c * e
```

饱和函数 `sat(x)` 在 `x<-1` 时返回 -1，在 `-1<=x<=1` 时返回 x，在 `x>1` 时返回 1。`phi` 是将 s 归一化的正宽度，与 s 同单位。

趋近律是对 s 随时间变化方式的规定。没有扰动且输出能完整执行时，所选规则为：

```text
s_dot = -k * s - epsilon * sat(s / phi)
```

对 s 求导并代入模型，可得到控制律，即计算输出的公式：

```text
u_request = (r_ddot - c * error_rate - k * s
             - epsilon * sat(s / phi)) / b
u = max(output_min, min(output_max, u_request))
```

参数要求：b 有限且非零；c 和 phi 有限且大于零；k 和 epsilon 有限且非负，并且至少一个大于零；输出上下限有限且下限不大于上限。允许固定范围，例如 `[0,0]`，但这不代表还能到达目标。

首版只有这一种连续饱和形式，不包含符号函数模式、误差死区、目标差分器、积分、滤波器或终端分支。没有积分或目标历史，因此不需要 dt 参数。调用方仍须选择、提供给周边组件并验证真实计算周期，不能从接口没有 dt 推出周期无关。

## 3. 不可省略的结论边界

理想无扰动、未限幅时，代回可得到指定的 s_dot。令偏离度量 `V=s²/2`，其变化为 `V_dot=-k*s²-epsilon*s*sat(s/phi)`。它用于分析理想连续时间行为，不是任意离散调用、噪声或驱动器动态下的保证。

当使用饱和函数时，在面附近控制是连续的；有持续扰动时不保证严格零误差。例如在面附近、静止目标、未限幅及恒定 d 下，平衡位置误差为：

```text
e_equilibrium = d / [c * (k + epsilon / phi)]
```

它只对上述对象和条件成立。验证案例的 d=.4、c=4、k=6、epsilon=2、phi=.25，得到约 .007142857 rad；真实 C++ 实验约 .007142872 rad，不把这个残差隐藏成“完美抗扰”。

输出限制改变真实 s_dot；输入增益误差也改变真实动态。没有证明普通位置首版优于现有 PID 或 ADRC，没有证明任意参数和采样间隔均稳定。

## 4. 与三个参考的适配关系

- 保留 A/B 普通位置控制的 `e=测量−目标、s=error_rate+c*e` 结构。
- 使用明确的输入增益 b，控制输出除以 b，避免 A 附件与代码中 J 的倒数歧义。
- 目标变化率显式输入，不使用 A/C 未按时间归一化的差分，也不使用 C 的上一拍混合时序。
- 保留目标加速度项；B 的普通分支删去该项的行为不作为本库基线。目标静止时调用方显式填写两个零变化率。
- 切换强度 epsilon 与归一化宽度 phi 分开，不复制 B 的多重参数含义。
- 不使用仅根据位置误差就提前置零的规则，所以经过目标但还有速度时仍会计算制动作用。
- C 和 B 的误差幂分支不属于首版，没有混入主路径。

## 5. 一次调用与失败

全部公式以当前输入计算，不隐式推进对象或读取时间。所有输入、所需中间量和限幅前请求必须有限，才提交本次输出和诊断结果。若中间量已经溢出为无穷，不用最终限幅掩盖计算失败。

Calc 失败保持调用方输出变量、配置和最近一次成功结果不变。HasResult 仅表示曾有可读的成功结果，不表示刚才的失败调用已产生新命令。Init、SetParameters、SetLimits 成功后和 Reset 后，旧诊断失效；Reset 不改配置或范围，也不发送任何命令。

库不使用动态内存和异常，单精度计算；禁止以 fast-math 编译生产实现，因为其假设会破坏非有限数值检查。已用 C++11 进行主机构建与 M4/M7 交叉编译；验证范围见运行报告。
