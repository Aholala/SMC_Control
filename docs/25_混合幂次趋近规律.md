# 第25讲：改变滑模变量的趋近规律

前置内容：[怎样趋近滑模面](08_怎样趋近滑模面.md)、[连续处理](12_抖振与零附近的连续处理.md)、[完整闭环](22_C++完整实验与重启.md)。本讲保持普通位置关系s=v+c*e，改变s向0靠近的规则。

## 1. 幂次项是什么

**幂次是把一个数提升到某个指数的运算。** 例如4^.5=2，指数.5就是平方根。负数直接求某些非整数幂可能没有实数结果，因此本讲先取|s|再求幂，方向交给已有的sat函数。

原普通形式与新增形式分别为：

```text
普通：s_dot=-K*s-epsilon*sat(s/phi)
混合幂次：s_dot=-K*s-G*|s|^a*sat(s/phi)
```

K仍乘s，G是幂次项系数，a是指数，phi是连续处理宽度。本库保留两项，故称混合形式；没有把参考B的POWER分支误写成只含一项的幂次公式。

## 2. 不一定在任何地方都更强

取本节教学数值K=3、epsilon=G=4、a=.5、phi=.25，单位使用rad、s：

| s数值 | 普通变化率 | 混合幂次变化率 |
| --- | ---: | ---: |
| 4 | −16 | −20 |
| .25 | −4.75 | −2.75 |
| 0 | 0 | 0 |

两种规则在正s侧都让s减小，在负s侧让s增大；但相同系数数值下，大s处和小s处的强弱可以不同。不能只凭“幂次”这个名字说它一定更快、更稳或输出更小。

在连续处理区内，sat(s/phi)=s/phi，新增项变成 `-(G/phi)*|s|^a*s`。这已经不是理想符号函数形式。不能把理想符号形式的有限到达结论直接用在这里。

## 3. 从规则得到输出

位置误差e=实际角度−目标角度，v为对应速度差；对象为角加速度=b*u，目标加速度为r_ddot。仍有：

```text
s=v+c*e
s_dot=b*u-r_ddot+c*v
request=(r_ddot-c*v-K*s-G*|s|^a*sat(s/phi))/b
```

该输出由PowerPosition计算。它不累计误差，不需要dt；计算间隔仍由使用项目管理和验证。

以Q表示角度单位，s单位Q/s、s_dot单位Q/s²，因此G单位是 `Q^(1-a)/s^(2-a)`，与K的1/s不同。参考B把两处系数共用一个K，本库分开，避免把不同单位当成同一个调节量。指数也不再兼作切换强度或归一化宽度。

换角度单位时，若所有角度数值乘L，G也要乘 `L^(1-a)`；否则换单位后的行为不等价。这个换算已在主机公式检查中验证。

## 4. 手算和完整实验

明确点沿用b=2、c=2、K=3、G=4、a=.5、phi=2，输出±3A。e=.5rad、v=0、目标加速度0时，s=1：

```text
|s|^.5=1，sat(s/phi)=.5
request=(-3*1-4*1*.5)/2=-2.5A
```

e=2rad时s=4，得到请求−10A、输出−3A；e=−2rad时方向相反。零误差和零速度差但目标加速度6rad/s²时，输出仍为3A，目标加速度没有省去。

完整闭环采用同一对象、目标、初值和输出范围，对照普通位置与混合幂次：b=3、c=4、K=6、phi=.25，普通epsilon=2、混合G=2、a=.5，初始角度−.2rad、目标.5rad、输出±4A、dt=.001s、时长8s，无外力。

这里声明了两组系数，不把不同单位的G和epsilon叫作同一个物理参数；只观察所列参数下的轨迹，不下“某种控制器普遍更好”的结论。前一节标量变化率示例和本节闭环参数也分别记录，不混用数值。
