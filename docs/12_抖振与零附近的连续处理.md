# 第 12 讲：抖振与零附近的连续处理

前置内容：[滑模变量与滑模面](06_滑模变量与滑模面.md)、[从运动关系推导控制输入](09_从运动关系推导控制输入.md)、[外力与参数误差下的趋近条件](11_外力与参数误差下的趋近条件.md)。本讲只解释输出为什么可能快速反复变化，以及用连续函数替换符号函数后发生什么。

## 1. 先定义抖振

**抖振是控制过程中出现的快速反复变化现象，常表现为控制输出频繁来回切换，并可能伴随实际运动的细小振荡。** 一次正常的输出反向不等于抖振。

沿用滑模变量 `s=ė+ce`：e 为实际角度减目标角度，ė 为误差变化率，c>0 为固定系数。角度用 rad，时间用秒；s 单位为 rad/s，s=0 对应滑模面。

先回顾符号函数 sign(s)：s 为正返回 +1，为零返回 0，为负返回 −1。即使 s 只从很小的正值变成很小的负值，函数结果也会从 +1 变成 −1。

第 9 讲的电流公式中有一项：

```text
u_switch = -(ε/b) × sign(s)
```

**u_switch 是完整控制电流中由符号项贡献的部分**，不是全部电流。b 是每安培引起的角加速度，单位 rad/(s²·A)；ε 为切换项系数，单位 rad/s²。因此 ε/b 的单位是 A。

## 2. 为什么很小的测量变化能产生很大的输出变化

**测量噪声是测量数值相对真实量的额外变化或误差。** 这里把它作用在算出的 s 上，记为 n，单位 rad/s；供计算使用的数为 `s_measured=s_true+n`。

教学假设 b=5 rad/(s²·A)、ε=2 rad/s²。若真实 s=0，而测量值因误差在 +.01 与 −.01 rad/s 之间交替：

```text
s_measured = +.01  →  u_switch = -.4 A
s_measured = -.01  →  u_switch = +.4 A
```

s 的变化很小，符号项的电流却反复相差 .8 A。符号函数只取方向，不会因为非零 s 很小而减小切换幅度。这是一种导致输出快速反复变化的机制。

本讲先用人为交替误差展示这种机制，不把它当成真实传感器的全部噪声。实际控制中，间隔计算造成的越过零、执行端响应不及时等也可能使切换反复发生；本讲不展开这些独立因素，也不把所有抖振归因于噪声。

## 3. 先定义连续处理使用的函数

**连续表示输入足够小的变化不会引起输出突然发生有限大小的跳变。** 本讲使用的标准饱和函数 sat(x)，把一个没有单位的输入限制在 −1 到 +1 之间：

```text
          -1，x < -1
sat(x) =   x，-1 ≤ x ≤ 1
          +1，x > 1
```

例如 sat(.1)=.1、sat(2)=1、sat(−2)=−1。连接处两侧结果相同，所以该函数连续；它在连接处仍有折角，不要求整条曲线处处圆滑。

由于 s 有单位，不能直接把它当作上面没有单位的 x。引入 φ（读作 phi），取正值、单位与 s 相同，使用 `x=s/φ`。

**边界层是滑模面附近采用连续过渡的一片区域。** 本讲以 `|s|≤φ` 定义它；φ 表示从零到两侧边界的阈值，整个 s 区间为 −φ 到 +φ，总跨度为 2φ。它不是位置误差死区，里面的非零 s 仍会产生控制作用。

现在将符号项改为：

```text
u_switch = -(ε/b) × sat(s/φ)
```

|s|≥φ 时与 sign 形式相同；|s|<φ 时按 `s/φ` 连续变化。在零点两种函数都返回零，区别是零附近怎样变化。

## 4. 用同一组数比较

仍取 b=5、ε=2，新增教学假设 φ=.1 rad/s：

| s / (rad/s) | sign(s) | sat(s/φ) | sign 形式 u_switch / A | sat 形式 u_switch / A |
| ---: | ---: | ---: | ---: | ---: |
| −.2 | −1 | −1 | +.4 | +.4 |
| −.1 | −1 | −1 | +.4 | +.4 |
| −.01 | −1 | −.1 | +.4 | +.04 |
| 0 | 0 | 0 | 0 | 0 |
| +.01 | +1 | +.1 | −.4 | −.04 |
| +.1 | +1 | +1 | −.4 | −.4 |
| +.2 | +1 | +1 | −.4 | −.4 |

因此对第 2 节同一段 ±.01 测量误差，φ=.1 时电流贡献在 −.04 与 +.04 A 间变化，相邻差值从 .8 A 降为 .08 A。输出仍在反复变化；这里降低的是幅度，没有改变误差交替的次数，也不能据此宣称实际机器人完全消除了抖振。

φ 与 ε 必须区分：ε 决定符号项在区域外的强度，φ 决定连续过渡覆盖多大的 s 范围。本实验只改变 φ，其他参数和测量序列都相同。

## 5. 连续以后，趋近关系也改变了

第 11 讲中 d 为额外角加速度。K>0 是乘 s 的系数，单位 1/s；ṡ 是 s 的时间变化率。准确模型、连续时间、输入完整执行、无测量误差时，把新的完整控制公式代回，有：

```text
ṡ = -K × s - ε × sat(s/φ) + d
```

在 `|s|≤φ` 内，将 sat(s/φ)=s/φ 代入：

```text
ṡ = -(K + ε/φ) × s + d
```

令 a=K+ε/φ，单位为 1/s。a 是本节新关系中乘 s 的固定系数。

无扰动 d=0 时变成 `ṡ=−as`，正是第 7 讲已研究的比例衰减关系：s 从非零初值逐渐接近零。不能直接沿用理想 sign 形式的有限时间首次到零结论。

若 d 为恒定值，**平衡值是使变化率为零、能在这些固定条件下保持不变的值**，本例记为 s_eq：

```text
0 = -a × s_eq + d
s_eq = d/a = d/(K + ε/φ)
```

这个式子必须检查 `|s_eq|≤φ` 才能用于本节内部关系。若初值也在该区域内，恒定 d 下的准确曲线为：

```text
s(t) = s_eq + [s(0)-s_eq] × exp(-a×t)
```

t 为经过的时间，s(0) 为初值，exp 是第 7 讲介绍的指数函数。它表示到平衡值的差按固定比例衰减；曲线始终位于初值与平衡值之间，所以两者都在区域内时，该内部关系全程适用。

令 K=1 /s、ε=2 rad/s²、d=1 rad/s²、s(0)=0，得到：

| φ / (rad/s) | a / (1/s) | s_eq / (rad/s) |
| ---: | ---: | ---: |
| .02 | 101 | 1/101，约 .009901 |
| .1 | 21 | 1/21，约 .047619 |
| .5 | 5 | 1/5，即 .2 |

三个平衡值都在各自的边界层内。在这组固定条件下，φ 较大时，前面的测量误差引起的电流变化幅度较小，但恒定扰动下 s 的平衡偏差较大。这是两个分别成立的实验结果，不是任意机器人上的统一最优参数结论。

这里的 s_eq 不是位置误差 e 的平衡值。本讲不重建完整位置运动，也不加入第 13 讲才讨论的最终输出大小限制。

## 6. MATLAB 做什么、怎样看图

入口：[run_lesson.m](../matlab/教学/第12讲_抖振与零附近的连续处理/run_lesson.m)，或根目录 [start.m](../start.m) 设置 `mode='教学'、number=12`。只依赖 MATLAB，无额外工具箱。

所有参数均为教学假设：b=5、K=1、ε=2，φ 取 .02/.1/.5，单位如上。实验分为两部分：

1. **测量回放**：真实 s 假设为零，同一段人为测量误差按 .01 s 间隔在 ±.01 rad/s 之间交替，共 201 个点。分别代入 sign 和三个 φ 的 sat 公式，只比较 u_switch；输出不会反过来驱动对象。这不是闭环控制实验。
2. **独立理想曲线**：没有测量噪声，恒定 d=1、初始 s=0，按上一节准确关系画三个 φ 的 s(t)，检查变化率、边界层条件和趋向的平衡值。取点间隔 .001 s 只用于画曲线，不是控制器周期。

图中左上为函数形状，sign 在零处断开并单独标出 sign(0)=0，避免画成连续斜线；右上为同一段测量误差；左下为它产生的符号项电流贡献；右下为另一个无测量误差实验中的扰动曲线。两个时间图只放大显示测量回放的前 .12 s，完整 2 s 数据仍输出。

**相邻输出差值**是两次连续结果相减后的大小，用来描述这段序列每次变动多大；程序取其中最大值。sign 与 φ=.02/.1/.5 的预期结果分别为 .8/.4/.08/.016 A。三种 sat 形式仍保留了交替，不能将“幅度变小”写成“次数变少”。

程序检查手算点、边界连接、区域外与 sign 相同、正负对称、各 φ 的相邻电流差值、恒定扰动平衡值、准确曲线代回，以及无扰动的非零初值比例衰减。输出位于 `build/教学/第12讲_抖振与零附近的连续处理/`，保留 PNG、FIG、CSV、MAT 参数数据和 JSON 报告。
