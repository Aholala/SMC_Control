# 第 09 讲：怎样从运动关系算出控制输入

前置内容是[电机输入与角速度](03_电机输入与角速度.md)、[误差与误差变化率](02_误差与误差变化率.md)、[滑模变量与滑模面](06_滑模变量与滑模面.md)、[怎样趋近滑模面](08_怎样趋近滑模面.md)。本讲只做推导与当前时刻的代回检查，不运行完整闭环。

## 1. 先定义要算的东西和前提

**控制律是根据目标、测量和参数，计算控制输入的公式。** 本讲控制输入记为 u，单位选为电流 A。

假设模型准确，输入立即作用，没有摩擦、重力等额外影响，输出没有受到大小限制。角度统一使用弧度 rad，时间使用 s。

沿用第 3 讲的输入增益概念：b 表示每单位输入对应多少角加速度，单位 rad/(s²·A)，已知且非零。固定单位、方向和模型下，输入与运动关系为：

```text
实际角加速度 = b × u
```

这是假设关系，不代表真实电机已经完成参数测量。本讲 b=5 的基准值可与第 3 讲同轴 Kt/J 的教学例子对应；反向增益案例只是明确设置的另一种方向约定。

## 2. 必要符号和单位

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| θ | 实际角度 | rad |
| r | 目标角度，也就是此前的 θd | rad |
| θ̇、ṙ | 实际角速度、目标角速度 | rad/s |
| θ̈、r̈ | 实际角加速度、目标角加速度 | rad/s² |
| e | 实际角度减目标角度 | rad |
| ė | 误差变化率 | rad/s |
| ë | 误差变化率本身的变化率 | rad/s² |
| c、K | 前两讲的正系数 | 1/s |
| ε | 符号项的正系数 | rad/s² |
| s | ė+ce | rad/s |
| ṡ | s 的时间变化率 | rad/s² |

一个点表示一次时间变化率，两个点表示再求一次变化率。**求导就是计算一个量随时间的变化率。** 本讲只用到两个规则：两项之差的变化率是两项变化率之差；固定常数乘某个量，其变化率是该常数乘这个量的变化率。

sign(s) 仍使用第 8 讲定义：正、零、负分别返回 1、0、−1。

## 3. 从误差连接到输入

从误差定义开始：

```text
e = θ - r
ė = θ̇ - ṙ
ë = θ̈ - r̈
```

再将模型 `θ̈=b×u` 代入，得到：

```text
ë = b × u - r̈
```

因此误差的加速度不是只看电机产生的加速度，还要减去目标本身的加速度。

## 4. s 的变化率怎样连接到 u

已知 `s=ė+ce`，c 在本讲不随时间变化。对两项分别计算变化率：

```text
ṡ = ë + c × ė
```

代入上一节：

```text
ṡ = b × u - r̈ + c × ė
```

这条式子描述在当前模型里，输入 u 怎样影响 s 的变化。它还没有指定想要什么运动。

第 8 讲已经规定希望的变化率：

```text
期望 ṡ = -K × s - ε × sign(s)
```

为了让模型产生这个结果，把两边设为相等：

```text
b × u - r̈ + c × ė = -K × s - ε × sign(s)
```

将其他项移到右边，再除以已知非零的 b：

```text
b × u = r̈ - c × ė - K × s - ε × sign(s)
u = [r̈ - c × ė - K × s - ε × sign(s)] / b
```

这就是当前假设下的控制律。括号里每项都是 rad/s²，除以 b 后得到 A，不是把期望的 ṡ 直接当作电流。

## 5. 最小手算例子与代回

本讲重新给出一组带单位的教学参数：b=5 rad/(s²·A)，c=.5 /s，K=1 /s，ε=2 rad/s²。最后一个参数不是第 8 讲 2°/s² 的单位转换，不把两讲当作同一个物理配置比较。

目标静止在 0 rad，实际角度 1 rad，实际角速度 0，目标加速度也为零：

```text
e = 1 rad
ė = 0 rad/s
s = 0 + .5 × 1 = .5 rad/s
期望 ṡ = -1 × .5 - 2 × 1 = -2.5 rad/s²
u = [0 - .5 × 0 - 1 × .5 - 2 × 1] / 5 = -.5 A
```

独立按模型检查：

```text
实际角加速度 = 5 × (-.5) = -2.5 rad/s²
误差加速度 = -2.5 - 0 = -2.5 rad/s²
模型产生的 ṡ = -2.5 + .5 × 0 = -2.5 rad/s²
```

恰好等于期望。这里是一个时刻的代回检查，不是完成了真实运动或证明任意间隔下稳定。

## 6. 为什么保留目标加速度

再看另一个时刻：实际角度和速度都与目标相同，因此 e=0、ė=0、s=0；但目标正在以 1 rad/s² 加速。

期望 ṡ=0，控制律仍给出 `u=1/5=.2 A`，用于产生相同的实际加速度。若漏掉目标加速度项，算出 u=0，误差加速度就成了 `0−1=−1 rad/s²`，不能实现期望结果。

同样，若把括号中的加速度数值直接当作电流、忘记除以 b，最小例子会发出 −2.5 A，模型产生 −12.5 rad/s²，与期望 −2.5 相差 −10 rad/s²。它们都会被代回检查发现。

## 7. 对应参考与生产库

复旦新版 [README.md](../smc/README.md) 第 154～166 行、川大 [SMC_Doc.tex](../Sliding/Documentation/SMC_Doc.tex) 第 100～105、127～129 行按相同思路推导。参考把输出写作 J 乘括号，统一到本讲明确输入增益后，该乘法系数对应 1/b；不能直接与物理转动惯量混用。

川大普通位置代码的活动分支省去了目标二次变化率，而包含该项的公式留在注释中。本讲核对的是推导中的完整目标加速度公式，不声称活动分支在加速目标下也精确实现同一趋近律。

当前库 [ALG_SMC.cpp](../main/ALG_SMC.cpp) 第 101～118 行分别计算 c×ė、K×s、零附近连续处理项，再用目标加速度减去这些项，最后除以 input_gain。

本讲仍采用第 8 讲理想符号函数。生产库使用连续形式并有最终输出限制，不能把本讲 sign 公式的具体数值直接当作库的所有输出。连续形式和限制的具体影响仍按后续课次展开。

## 8. MATLAB 实验

入口：[run_lesson.m](../matlab/教学/第09讲_从运动关系推导控制输入/run_lesson.m)，或在根目录 [start.m](../start.m) 设置 `mode='教学'、number=9`。仅需 MATLAB，不依赖 C++、Simulink 或额外工具箱。

全部参数为教学假设，单位 rad、s、A。以下是图中的五个场景，c、K、ε 如第 5 节：

| 场景 | 实际角度/速度 | 目标角度/速度/加速度 | b | 手算 u |
| --- | --- | --- | ---: | ---: |
| A | 1 rad，0 rad/s | 0 rad，0 rad/s，0 rad/s² | +5 | −.5 A |
| B | 1 rad，−1 rad/s | 0 rad，0 rad/s，0 rad/s² | +5 | +.6 A |
| C | 2 rad，.5 rad/s | 2 rad，.5 rad/s，1 rad/s² | +5 | +.2 A |
| D | −1 rad，0 rad/s | 0 rad，0 rad/s，0 rad/s² | +5 | +.5 A |
| E | 1 rad，0 rad/s | 0 rad，0 rad/s，0 rad/s² | −5 | +.5 A |

表中 b 的单位均为 rad/(s²·A)。B 的当前误差与 A 相同，但速度不同；E 用相反的输入增益，所需电流方向也反过来，模型产生的角加速度保持一致。

左图画输入 A，右图画期望和代回得到的 ṡ，两者单位不同。程序检查五个手算点、目标加速度、方向映射及两个故意缺项的错误；另外以两种 b、五种误差、三种误差变化率、两种目标加速度构成 60 个点检查代回结果。

输出位于 `build/教学/第09讲_从运动关系推导控制输入/`，包含 PNG、FIG、五点 CSV、60 点 CSV、MAT 参数数据和 JSON 报告。`plant_acceleration` 是模型实际角加速度，`error_acceleration` 是误差加速度，`reconstructed_s_rate` 是经过模型重建的 s 变化率。

本实验没有时域闭环、输出限制、外力或采样延迟，没有调用生产库。它只说明在已声明模型中，代数计算能产生期望变化率；不替代完整控制或硬件验证。生产库和参考保持不变，个人理解另行确认。
