# 第 03 讲：电机输入怎样改变角速度

本讲只建立从电机电流到转动的基本关系，不设计控制器。前置内容是[角度与角速度](01_角度与角速度.md)；上一讲的误差暂不参与计算。

## 1. 先补齐必要的量

**角加速度是角速度随时间的变化率。** 例如角加速度恒为 10°/s²，表示每过 1 s，角速度就增加 10°/s。负角加速度表示角速度数值在减少；是否减慢，要结合当时的转动方向。

**力矩是力使物体绕某根轴转动的作用。** 电机输出力矩会推动转轴转动，单位为牛顿米，写作 N·m。可以先把它理解为“绕轴的推转作用”，不展开力与作用位置的详细关系。

**转动惯量是描述物体绕指定轴的角速度有多难改变的物理量。** 它由质量及质量相对该轴的分布共同决定，单位为 kg·m²。同样的力矩作用下，转动惯量越大，角速度改变得越慢。它不是角度，也不是电机电流。

接下来还需要另一种角度单位：**弧度 rad 是用圆弧长度与半径的比值度量角度的单位。** 例如半径 1 m 的圆上，转过的圆弧长为 1 m，对应 1 rad。1 rad 约为 57.3°；一整圈约为 6.283 rad。

本讲机械公式使用 rad、rad/s、rad/s²，不能直接把以度表示的数值代入而不换算。这里先知道单位含义与换算即可，不展开圆的几何推导。

## 2. 力矩与角加速度怎样联系

以下限定在同一根固定转轴，转动惯量不变，并暂时忽略摩擦、重力等额外力矩。先说明符号：

- `T`：作用在该轴上的总力矩，N·m；在本讲假设下等于电机输出力矩。
- `J`：该轴的物理转动惯量，kg·m²，必须为正。
- `α`：角加速度，rad/s²。

关系为：

```text
T = J × α
α = T / J
```

在相同 J 下，力矩加倍，角加速度加倍；在相同力矩下，J 加倍，角加速度变成一半。

## 3. 电流怎样进入这个关系

**转矩常数是把电流换算成电机输出力矩的比例系数。** 记为 `Kt`，单位 N·m/A。`I` 表示与该系数定义一致、以安培 A 表示的实际电流；Kt 与 J 都对应同一转轴。

本讲把电机简化为力矩与电流成正比，并假定所给电流立即执行：

```text
T = Kt × I
```

代入上一节，得到：

```text
α = (Kt / J) × I
```

这说明本模型中，电流首先决定角加速度，再通过角速度的持续变化影响角度。恒定电流不等于恒定角速度。

真实项目需确认实际电流含义、正方向、同轴参数和额外力矩，不能将协议命令数值直接当作安培；本讲不讨论驱动器的内部控制。

## 4. 用一组教学参数手算

以下数值仅为教学假设，不来自开源的实机参数：

| 量 | 假设值 |
| --- | --- |
| 物理转动惯量 J | .02 kg·m² |
| 转矩常数 Kt | .1 N·m/A |
| 恒定电流 I | .2 A |
| 初始角速度 | 0 rad/s |
| 初始角度 | 0 rad |

先算力矩，再算角加速度：

```text
T = .1 × .2 = .02 N·m
α = .02 / .02 = 1 rad/s²
```

由于角加速度保持 1 rad/s²，角速度从零开始，每过 1 s 增加 1 rad/s。因此 1 s 后角速度为 1 rad/s。

平均角速度指一段时间里总角度变化除以总时间。本段角速度从 0 均匀增加到 1 rad/s，因此平均角速度是两端的平均值 .5 rad/s，转过角度为 `.5 rad/s×1 s=.5 rad`。

用符号整理恒定角加速度的计算关系。`ω0、θ0` 是初始角速度和角度，`t` 为经过的时间；`ω、θ` 是当前角速度和角度：

```text
ω = ω0 + α × t
θ = θ0 + ω0 × t + .5 × α × t²
```

这些公式只用于角加速度恒定的这一段运动。本讲用它们直接计算每个时刻，不做逐次近似更新；后者留到下一讲。

## 5. 物理惯量和代码中的输入增益要分清

**输入增益是输入对所建模型中运动变化量的比例系数。** 在本讲中，它表示每单位电流对应多少角加速度，记为 b：

```text
b = Kt / J
α = b × I
```

b 的单位为 rad/(s²·A)。本例 `b=.1/.02=5 rad/(s²·A)`。

再看它的倒数，也就是 1 除以 b：

```text
1/b = J/Kt = .2 A·s²/rad
```

三个数要分开：物理惯量是 .02 kg·m²，输入增益是 5 rad/(s²·A)，逆输入增益是 .2 A·s²/rad。它们的含义、单位和数值不同。

川大 [SMC_Doc.tex](../Sliding/Documentation/SMC_Doc.tex) 第 46、53、60 行依次写出 `T=Jα`、`T=KtI`、`α=(Kt/J)I`；第 63～65 行把系数合并后仍称为 J。合并后对应的是原 `J/Kt`，不能再把它直接当作纯物理惯量。

当前库 [ALG_SMC.hpp](../main/ALG_SMC.hpp) 的 `input_gain` 对应这里的 b；若输入单位为 A，角度单位为 rad，并满足本讲模型，才可用同轴的 Kt/J 计算。换成其他输入、角度单位或方向后，应重新换算。复旦旧版 J 的文档与代码差异仍按来源核查保留，不在本讲扩展控制律。

## 6. MATLAB 实验

入口：[run_lesson.m](../matlab/教学/第03讲_电机输入与角速度/run_lesson.m)，直接运行整个文件，或在根目录 [start.m](../start.m) 设置 `mode='教学'、number=3`。

只依赖 MATLAB，不需要 C++、Simulink 或其他工具箱。本讲四个独立场景全部从静止、零角度开始，持续 1 s：

| 场景 | I / A | J / (kg·m²) | α / (rad/s²) | 1 s 后 ω / (rad/s) | 1 s 后 θ / rad |
| --- | ---: | ---: | ---: | ---: | ---: |
| 基准 | .2 | .02 | 1 | 1 | .5 |
| 电流加倍 | .4 | .02 | 2 | 2 | 1 |
| 惯量加倍 | .2 | .04 | .5 | .5 | .25 |
| 反向电流 | −.2 | .02 | −1 | −1 | −.5 |

所有场景 Kt 均为 .1 N·m/A。`plot_step_s=.01 s` 只控制图上取点的密度，不是控制器周期。图上应看到恒定角加速度、随时间直线变化的角速度，以及弯曲变化的角度。

脚本核对力矩、角加速度、末速度、末角度、电流/惯量比例、输入增益及其倒数。还有一个不绘图的小检查：如果开始已经以 2 rad/s 转动，随后电流为零，在忽略其他力矩的本模型中，角速度仍保持 2 rad/s。零电流对应零角加速度，不自动把速度变为零。

输出目录为 `build/教学/第03讲_电机输入与角速度/`，包含 PNG、FIG、场景参数 CSV、角度/速度 CSV、MAT 数据和 JSON 运行报告。数据列名中的 `rad_s` 表示 rad/s，`rad_s2` 表示 rad/s²，`kg_m2` 表示 kg·m²。
