# 第 21 讲：同一输入序列的 MATLAB 与 C++ 逐次核对

前置内容：[从公式阅读最小 C++ 实现](19_从公式阅读最小C++实现.md)、[初始化失败与多个实例](20_初始化失败与多个实例.md)。本讲核对正常数值计算，不推进运动对象。

## 1. 什么叫逐次核对

**逐次核对是给两个实现相同的、有顺序的输入，再按序号比较每一次计算的各个输出。** 它既检查最后的电流，也检查位置误差 e、误差变化率、滑模变量 s、限幅前请求和限幅标志。

例如两个算法最后都输出 +3 A，可能只是请求都超过上限；一个请求 +5 A，另一个请求 +50 A，仍然可能同时输出 +3 A。因此请求与最终输出要分列检查。

本讲的 C++ 程序 [position_sequence_runner.cpp](../examples/position_sequence_runner.cpp) 只调用现有生产库。一个 block 是配置和输出范围不变的一段输入；每段开始初始化，段内连续调用同一个实例，不逐行重新初始化。MATLAB 按同一公式独立算预期，不调用 C++ 代替自己的计算。

## 2. 为什么本讲需要允许差

**浮点数是用有限位数近似表示实数的数字形式。** 本机 C++ 的 float 与 MATLAB 的 single 使用单精度表示，MATLAB 的 double 使用更多位数的双精度表示。有限位数意味着一些数和运算结果需要取邻近可表示值，两种计算的末尾数字可能不同。

为确保输入相同，本讲先把参数、范围和五个输入转换为 single，再转换回 double 写入共同 CSV。C++ 把这些数读为 float；MATLAB 用同一批已转换输入进行 double 独立计算。两边共有输入值，后续计算各自进行。

**允许差是运行前约定的数值差异上限**，这里不把“通过”写成“所有位都一样”。设某列的 C++ 数值为 x，MATLAB 参考为 y，检查：

```text
δ = x − y
|δ| ≤ a + r × |y|
a = 1×10⁻⁵，r = 3×10⁻⁶
```

a 是绝对允许差的数值，r 是随参考量大小增加允许差的比例；r 没有单位。每一列在自己的单位下检查：角度 rad、速度与 s 为 rad/s、电流 A。这里使用同样的阈值数值，未把不同单位合成一个物理差值。这一条件沿用既有库的单次公式核对，不在观察结果后调整。

限幅标志与成功标志是真假判断，不使用上述小数容差，要求逐次完全相同。检查数值差 δ 时，也要与控制误差 e=测量−目标区分。

## 3. 共同输入包含什么

共同 CSV 每行依次为：block、b、c、K、ε、φ、输出下限、上限、目标角度、目标速度、目标加速度、测量角度、测量速度。符号与单位沿用第 19 讲；所有参数仍是教学假设。

| 分段 | 数量 | 参数 [b,c,K,ε,φ] | 电流范围 / A |
| --- | ---: | --- | --- |
| 0：明确点 | 16 | [2,2,3,4,2] | [−3,3] |
| 1 | 1024 | [2,2,3,4,2] | [−1.5,2.25] |
| 2 | 1024 | [−2,2,3,4,2] | [−1.5,2.25] |
| 3 | 1024 | [3,4,6,2,.25] | [−1.5,2.25] |
| 4 | 1024 | [−3,4,6,2,.25] | [−1.5,2.25] |

16 个明确点包括第 19 讲的六点、零点、连续处理正负边界及两侧相邻 float 输入、恰好等于电流上下限、s=0 的非零误差点，以及位置/速度已匹配但目标加速度非零的点。

例如 φ=2、速度误差为零、c=2 时，测量误差为 1 对应 s=φ。本机小于 1 的相邻 single 值约为 .9999999403953552，大于 1 的相邻值约为 1.0000001192092896。它们用于检查分段边界附近，不是对象运动轨迹。

四组长序列共用相同的五列输入。n=0～1023 仅为序号，不表示秒：

```text
目标角度 = 1.2 sin(.013 n)
目标速度 = .7 cos(.017 n)
目标加速度 = .4 sin(.031 n)
测量角度 = .8 cos(.019 n)
测量速度 = .6 sin(.023 n)
```

这些是覆盖正常计算数值的独立测试输入，不主张五列合起来是一条物理运动的导数关系。物理闭环放在第 22 讲检查。

## 4. 独立公式检查哪些步骤

MATLAB 根据共同输入，独立计算：

```text
e = measurement − target
error_rate = measurement_rate − target_rate
s = error_rate + c e
request = [target_acceleration − c error_rate − K s − ε sat(s/φ)] / b
output = max(minimum, min(maximum, request))
limited = request 与 output 是否不同
```

sat 为第 12 讲定义的连续分段处理。每行五个数值字段按允许差检查，limited 精确检查。第 19 讲的六个手算电流还以明确常数再查一次，避免只靠大量近似数据掩盖基本方向、少项或限幅错误。

**首次超差位置是按输入顺序找到的第一条不满足检查条件的记录。** 程序会记录其序号和字段再报错，而不只给一个总体最大差。它与“首次非零差”不同：一个非常小且满足允许差的差值不会导致失败。

## 5. 实际结果

2026-10-29 使用 MATLAB R2025b（25.2.0.2998904）、g++ 16.1.0、C++11 实际运行，进程返回 0，报告 passed=true。共 4112 次真实 Calc，五段输入，每段内保留同一实例。

| 比较字段 | 最大绝对差，单位按该列 |
| --- | ---: |
| e / rad | 5.96×10⁻⁸ |
| error_rate / (rad/s) | 5.96×10⁻⁸ |
| s / (rad/s) | 4.92×10⁻⁷ |
| 请求 / A | 2.12×10⁻⁶ |
| 输出 / A | 7.65×10⁻⁷ |
| limited | 0，全部精确一致 |

首次非零数值差出现在第 8 行，没有任何超差行。每行把“绝对差÷允许差”取五列最大值，全部记录中的最大比例约 .0467，即用了允许差的 4.67%；这不是电流相对误差为 4.67%。
