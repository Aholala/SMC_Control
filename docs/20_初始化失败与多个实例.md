# 第 20 讲：初始化、失败和多个实例的行为

前置内容：[初始化复位与旧输出](15_初始化复位与旧输出.md)、[从公式阅读最小 C++ 实现](19_从公式阅读最小C++实现.md)。本讲只调用现有库，观察正常数值之外的行为，不推进对象运动。

## 1. 先区分三种东西

**对象状态是某个控制器对象当前保存的信息。** 这里包括参数、输出范围、是否初始化，以及最近一次成功计算的结果。**初始化是检查并安装一组参数和范围，使对象可以接受计算的操作。** **实例是按同一个类建立的一个具体对象。** 两个 `SMC::Position` 实例使用同一份代码，但各自保存自己的状态。

第 19 讲的 `float command` 是调用方自己的变量。它与对象内保存的 `result.output` 不是同一个变量；成功 Calc 会把新输出写给它，Reset 没有接收这个变量，因此不会替调用方改写它。

还要把两个判断分开：

| 判断 | 它回答什么 |
| --- | --- |
| IsInitialized() | 对象是否已经成功安装参数和范围？ |
| HasResult() | 对象是否保存着有效的最近一次成功结果？ |
| 本次 Calc 返回值 | 本次输入是否成功算出了新结果？ |

例如先成功计算，再给出错误输入：本次 Calc 返回 false，但 HasResult 仍可为 true，因为旧的成功结果还保留着。读取诊断结果前应检查 HasResult；使用本拍新输出应检查本次 Calc 的返回值。

## 2. 哪些参数与输入有效

**有限数是能用一个有限大小表示的数。** 浮点数还可能带有特殊标记：NaN 表示不是一个有效数值，正负无穷表示不是有限大小。**溢出是一次运算结果超出了所用数字类型能表示的范围。** 即使两个输入都是有限数，它们相减或相乘后仍可能溢出。

沿用公式符号：b 为输入增益，c 为误差组合系数，K 和 ε 为两个趋近项的系数，φ 为滑模变量连续处理的正阈值；各项单位见第 19 讲。本库检查：

| 项目 | 要求 |
| --- | --- |
| b | 有限且不为零，允许负值 |
| c、φ | 有限且大于零 |
| K、ε | 有限且不小于零，两者不能同时为零 |
| 输出下限、上限 | 都有限，下限不大于上限；可以相等 |
| 本次五个输入 | 都有限 |
| 计算所需中间数及最终请求 | 都有限，检查后才提交结果 |

默认配置全部为零，不满足这些要求。因此“创建对象”与“成功初始化”是两个步骤。`std::isfinite` 是 C++ 中判断一个数是否有限的函数；源码用它检查输入和中间量。

## 3. 成功和失败分别改变什么

**诊断结果就是用于观察计算过程的已保存数值**，包括 e、误差变化率、s、请求、输出和限幅标志。清除诊断会把这些保存值清零，并令 HasResult=false；此时零值不代表已经算出了零输出。

| 操作 | 成功后的对象行为 | 失败后的行为 |
| --- | --- | --- |
| Init | 安装参数与范围，清除诊断，标记已初始化 | 保持已有对象；未初始化对象仍未初始化 |
| SetParameters | 保留范围，替换参数，清除诊断 | 保持对象 |
| SetLimits | 保留参数，替换范围，清除诊断 | 保持对象 |
| Reset | 保留参数和范围，清除诊断 | 保持对象 |
| Calc | 保存新诊断，并改写传入的 command | 对象与传入的 command 都保持原样 |

未初始化对象的 Calc、Reset、SetParameters、SetLimits 都会失败。Init、改参、改范围和 Reset 都不接收外部 command，所以不会修改它。

例如原 command=−2.5 A，随后 Calc 失败：这个变量仍是 −2.5 A，不能因为变量里还有数就称它为本次新结果。使用项目需要检查返回值，再执行项目已定义的失败处理；库不能替具体机器人决定失败后如何驱动设备。

## 4. 两个对象的简单手算

沿用 `[b,c,K,ε,φ]=[2,2,3,4,2]`，角度 rad、时间 s、输出 A。对象 A 范围为 [−3,3] A；对象 B 仅把 b 改为 −2，范围为 [−1,2] A。全部数值是教学假设。

对两者都给目标零、测量 .5 rad、测量速度零：

```text
e=.5 rad，误差变化率=0，s=1 rad/s，sat(s/φ)=.5。
括号内请求角加速度 = 0−0−3−2 = −5 rad/s²。
A：请求 −5/2 = −2.5 A，输出 −2.5 A。
B：请求 −5/(−2) = +2.5 A，范围最多 +2 A，输出 +2 A。
```

在 A 失败、复位或改参时，同时检查 B 的参数、范围、结果和外部变量是否原样保留。这比只看“B 下次还能计算”更具体。

## 5. 本讲的 29 个操作

可运行主机程序为 [position_state_walkthrough.cpp](../examples/position_state_walkthrough.cpp)。初始外部变量设为 A=17、B=23，只是便于观察是否被改写的标记，不发送给任何设备。

| 序号 | 操作 | 返回预期与关键观察 |
| --- | --- | --- |
| 1～4 | 未初始化 A 计算、复位、改参、改范围 | 全部 false；变量仍为 17 |
| 5 | A 使用默认无效配置初始化 | false，仍未初始化 |
| 6～7 | 安装上述 A、B 配置 | true，诊断均无效，外部变量不变 |
| 8～9 | A、B 分别计算 .5 rad 点 | true，外部变量 −2.5、+2 A |
| 10 | A 输入 NaN 目标 | false，A 旧结果仍有效，B 不变 |
| 11 | B 输入负无穷目标速度 | false，两个完整状态均保持 |
| 12 | A 输入正无穷测量速度 | false，两个完整状态均保持 |
| 13 | A 的测量为最大有限 float，目标为其负值 | 相减溢出，false；不会先截成有限电流再称为成功 |
| 14～16 | A 无效改参、倒置输出范围、无效重新初始化 | 全部 false，保持原参数、范围与结果 |
| 17 | A Reset | true，A 诊断清零、HasResult=false，外部变量仍 −2.5 A |
| 18～19 | B、A 再算原点 | B 仍 +2 A，A 仍 −2.5 A |
| 20～21 | A 把 b 改为 −2，再算原点 | 改参后诊断失效；新输出 +2.5 A，范围仍 [−3,3] |
| 22～23 | A 范围改为 [−1,1]，再算原点 | 改范围后诊断失效；输出 +1 A |
| 24～25 | A 范围改为 [2,2]，再给目标加速度 6，其余输入零 | 请求 −3 A，但固定输出 +2 A，limited=true |
| 26 | B Reset | B 诊断失效，外部变量仍 +2 A；A 不变 |
| 27 | A 使用第 19 讲的 F 点 | 请求 −2.5 A，固定范围使输出仍 +2 A |
| 28～29 | A 重新安装初始配置，再算原点 | 初始化清诊断但不改外部变量；随后新输出 −2.5 A |

第 25 步说明下限等于上限是一个固定输出范围，不表示停机。它也可能迫使结果与请求方向相反。本讲没有把这种范围当作机器人策略。

CSV 中 operation=1/2/3/4/5 分别表示 Init/Calc/Reset/SetParameters/SetLimits。variant 对 Init/改参：0 为默认无效配置、1 为 b=2、2 为 b=−2；Init 变体 2 使用 B 的范围。对改范围：0 为 [2,−2]、1 为 [−1,1]、2 为 [2,2]。Calc 变体 1～7 依次为 .5 rad 点、仅目标加速度 6、NaN 目标、正无穷测量速度、相减溢出点、负无穷目标速度、F 点。这样可由每行前三个操作字段查回完整输入。
