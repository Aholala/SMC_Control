# 第 02 讲：误差与误差变化率

这一讲只回答：误差是什么，误差变化率是什么，为什么相同误差不一定对应相同的运动趋势。

前置内容：[角度与角速度](01_角度与角速度.md)。本讲仍只研究一根轴、同一零方向和正方向下的角度；没有跨圈表示，也没有控制器、电流或外力计算。

## 1. 误差是什么

**误差是实际值与目标值之间的差。** 在本课程中，固定采用“实际减目标”的约定：

```text
角度误差 = 实际角度 - 目标角度
```

例如，目标是 30°，实际是 20°，误差就是 `20°−30°=−10°`。

- 正误差：实际角度大于目标角度。
- 负误差：实际角度小于目标角度。
- 零误差：当前实际角度等于当前目标角度；这句话没有说明是否还在运动。

误差的正负由减法顺序决定，不是好坏的标志。其他控制器可以采用相反约定，但公式与代码必须一起对应，不能混用。

还要区分“误差数值”和“误差大小”。大小指不带正负的距离数值，也叫绝对值：−10° 的大小是 10°，−5° 的大小是 5°。因此从 −10° 变到 −5°，数值在增加，大小却在减少。

## 2. 误差变化率是什么

**误差变化率描述误差这个数值随时间变化的快慢和方向。** 角度误差用度表示时，它的变化率单位是 °/s。

误差变化率为 +5°/s 且保持不变，表示每过 1 s，误差数值增加 5°；为 −5°/s 时，表示误差数值每秒减少 5°。

注意，这里的“增加”描述带符号的数值，不等于离目标更远。例如误差从 −10° 变到 −5°，它的变化率为正，但正在靠近目标。

## 3. 一个相同误差、不同后续运动的例子

目标固定在 30°，两个场景的实际角度都从 20° 开始，所以初始误差都为 −10°。

| 场景 | 实际恒定角速度 | 1 s 后实际角度 | 1 s 后误差 | 这 1 s 内的趋势 |
| --- | ---: | ---: | ---: | --- |
| A | +5°/s | 20°+5°=25° | 25°−30°=−5° | 靠近目标 |
| B | −5°/s | 20°−5°=15° | 15°−30°=−15° | 远离目标 |

它们的初始误差相同，正在进行的运动却不同。这就是后面除了看误差，还需要看误差怎样变化的原因。本例只观察 1 s，不把运动延伸到越过目标之后再沿用“靠近”的说法。

不要记成“变化率为负就是靠近”。如果当前误差为正，负变化率可能使它靠近零；如果当前误差为负，负变化率则会使它变得更负。需要把当前误差与变化率一起看。

## 4. 怎样由两种角速度得到误差变化率

先说明接下来使用的符号与单位：

- `θ`：实际角度，°。
- `θd`：目标角度，°；下标 d 只是用来标出目标。
- `ω`：实际角速度，°/s。
- `ωd`：目标角速度，°/s，即目标角度本身变化的快慢与方向。
- `e`：角度误差，°。
- `ė`：误差变化率，°/s；e 上方的点表示它随时间的变化率。

误差是实际角度减目标角度。因此它的变化也要把目标的变化减去：

```text
e = θ - θd
ė = ω - ωd
```

目标静止时，`ωd=0`，此时误差变化率才等于实际角速度。

如果目标和实际都保持 +5°/s，且开始分别为 30°、20°，那么 1 s 后分别是 35°、25°。误差仍是 −10°，误差变化率是 `5−5=0°/s`。这里“误差不变”不等于“误差为零”，也不等于“实际没有运动”。

本讲直接给定角速度和目标角速度，不讨论怎样从测量数据估计它们。

## 5. MATLAB 实验

直接运行 [run_lesson.m](../matlab/教学/第02讲_误差与误差变化率/run_lesson.m)，或在根目录 [start.m](../start.m) 设置 `mode='教学'、number=2`。默认 number=1 保留为从第一讲开始的入口。

只依赖 MATLAB，不需要 C++、Simulink 或额外工具箱。参数均为教学假设，不来自参考开源的实机配置。

| 参数 | 值与单位 | 含义 |
| --- | --- | --- |
| `target_initial_deg` | 30° | 共同目标的初始位置 |
| `target_rate_deg_s` | 0°/s | 主实验的目标保持静止 |
| `measurement_initial_deg` | 20° | 两个场景的共同实际起点 |
| `measurement_rates_deg_s` | +5、−5 °/s | 两个场景的实际角速度，分别保持不变 |
| `duration_s` | 1 s | 观察时长 |
| `plot_step_s` | .01 s | 绘图取点间隔，不是控制器周期 |

上图应看到两条误差曲线都从 −10° 出发，分别到 −5° 和 −15°；下图应看到 +5°/s 与 −5°/s 两条恒定变化率。程序另检查一次目标与实际都以 +5°/s 运动时的结果。

自动检查包括共同初始误差、手算末值、变化率、当前区间的靠近/远离趋势，以及目标运动时不能省去目标角速度。输出在 `build/教学/第02讲_误差与误差变化率/`，保留 PNG、FIG、CSV、MAT 数据和 JSON 运行报告。

CSV 列名中的 `approach` 表示本区间靠近目标的场景，`depart` 表示远离场景，`moving` 表示目标与实际一起运动的小检查。`_deg` 为度，`_deg_s` 为度每秒。
