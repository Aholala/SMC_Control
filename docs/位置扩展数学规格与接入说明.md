# 位置扩展：累计、混合幂次和终端分段

本次在原有两个生产文件中新增三个独立控制器，原 Position、Velocity 的接口和计算代码保持不变。

| 控制器 | 它计算什么 |
| --- | --- |
| SMC::IntegralPosition | 把过去的位置误差累计后加入位置控制 |
| SMC::PowerPosition | 保留普通位置滑模变量，使用线性项与误差幂次项共同规定趋近速度 |
| SMC::TerminalPosition | 大误差区使用带符号误差幂，小误差区使用普通位置关系 |

生产文件仍为 [ALG_SMC.hpp](../main/ALG_SMC.hpp)、[ALG_SMC.cpp](../main/ALG_SMC.cpp)，C++11，无硬件、时钟或任务系统依赖。

## 1. 共同输入与输出

实际角度、角速度为 θ、ω，目标角度及其速度、加速度为 r、r_dot、r_ddot。误差 e=θ−r，速度差 v=ω−r_dot。对象沿用 `θ_ddot=b*u+d`，b为单位输入引起的角加速度，d为外力等折算的角加速度。

共同使用 PositionInput 的五个显式输入，不自动差分目标；初始化均为 `Init(config,output_min,output_max)`。所有输出使用最终范围限幅，返回最近成功的误差、滑模变量、请求、输出和限幅标志。

参数在初始化/更新时检查；计算入口只检查初始化，累计形式另外要求正dt，末尾检查请求及需提交的累计是否有限。延续用户要求的精简风格，不添加逐项中间量检查或累计限制。

共同接口为 SetParameters、SetLimits、Reset、Calc、GetConfig、GetResult、IsInitialized、HasResult。成功更新清除旧诊断，失败保持对象和外部command。Reset不发送设备命令；改参不承诺电流连续。

## 2. 位置累计形式

**位置误差累计 z 是把位置误差乘时间后逐次相加的状态。** 每次先更新，再计算：

```text
z_new = z_old + e*dt
s = v + c1*e + c2*z_new
request = (r_ddot - c1*v - c2*e - K*s - epsilon*sat(s/phi)) / b
```

IntegralPositionConfig 的字段为 input_gain=b、surface_gain=c1、integral_gain=c2、reaching_gain=K、switching_gain=epsilon、boundary_width=phi。c1>0、c2≥0，K和epsilon非负且不能同时为零，b非零、phi>0；参数均有限。

以Q表示角度单位、U表示输出单位：z单位Q·s，c1为1/s，c2为1/s²，s和phi为Q/s，epsilon为Q/s²，b为Q/(s²·U)。c2=0时输出公式退化为普通位置形式，累计状态仍按调用推进。

调用为 `axis.Calc(input,dt,command)`，GetErrorIntegral读取累计状态。Init与Reset清零累计；成功改参/改输出范围保留累计。累计不截断、不冻结。

与参考B的EISMC保留相同组合关系和−c2*e项，同时保留当前库显式目标加速度。原B执行式省略该项，不作为本库完整运动目标的基线。

## 3. 混合幂次趋近

**幂次是把一个量提升到指定指数的运算**，例如指数.5对应平方根。此处对|s|求幂，保持负s下也有明确实数结果：

```text
s = v + c*e
request = (r_ddot - c*v - K*s - G*|s|^a*sat(s/phi)) / b
```

PowerPositionConfig 的字段为 input_gain=b、surface_gain=c、reaching_gain=K、power_gain=G、exponent=a、boundary_width=phi。b非零、c/phi/a为正，K/G非负且不能同时为零；参数均有限。

a无单位，G单位为 `Q^(1-a)/s^(2-a)`；K仍为1/s。角度单位乘L时，b与phi乘L，G乘 `L^(1-a)`，否则换单位后公式不再等价。主机测试已检查该换算。

调用为 `axis.Calc(input,command)`，无累计状态。参考B的POWER执行式既含−K*s，也含−K*|s|^epsilon*Sat(s)；本库保留混合结构，将两项系数分为不同单位的K和G，并把指数a与宽度phi独立出来。

生产采用连续sat。理想符号形式在G>0、0<a<1时的有限到达分析，不能直接作为当前连续形式的有限时间保证。

## 4. 终端/普通分段形式

**带符号误差幂定义为 g(e)=sign(e)*|e|^a**，正负误差都对应实数。终端形式用这种非线性误差关系研究理想面内有限时间到零。本库使用参考C的小误差普通分支：

```text
当 |e| < delta：
    h(e) = c*e
    h_derivative = c
否则（包括恰好等于delta）：
    h(e) = beta*sign(e)*|e|^a
    h_derivative = beta*a*|e|^(a-1)
s = v + h(e)
request = (r_ddot - h_derivative*v - K*s - epsilon*sat(s/phi)) / b
```

TerminalPositionConfig 的字段为 input_gain=b、linear_surface_gain=c、terminal_gain=beta、exponent=a、reaching_gain=K、switching_gain=epsilon、boundary_width=phi、transition_width=delta。b非零，c/beta/phi/delta为正，0<a<1，K/epsilon非负且不能同时为零；参数均有限。

beta单位 `Q^(1-a)/s`，delta单位Q，c单位1/s。角度单位乘L时，beta乘 `L^(1-a)`，delta、b、epsilon和phi乘L，c/K/a保持。实际阈值必须由项目提供，示例的.25rad不是原C的1°，也不是机器人默认参数。

调用为 `axis.Calc(input,command)`，结果额外包含 terminal_branch，表示本次成功计算是否使用外区。先选分支，再计算相应表达式；内区不计算零处的负幂，也不把零位置误差直接当作零电流。

选择 `c=beta*delta^(a-1)` 可使两侧h值接续，但两侧导数分别为c与a*c，控制输出仍可能跳变。库不自动替换系数、插入平滑段或添加死区。

生产类只称终端/普通分段形式：普通内区与连续sat均不支持直接沿用“全程有限时间到零”的结论。纯终端面内解析关系见[第26讲](26_有限时间面内关系.md)，零附近与切换证据见[第27讲](27_零附近与分段切换.md)。

## 5. 最小调用位置

```cpp
// IntegralPositionConfig按本页字段填写；值和输出范围来自使用项目。
SMC::IntegralPosition integral_axis;
bool ready = integral_axis.Init(integral_config, project_min, project_max);
float command = 0;
if (ready && integral_axis.Calc(position_input, elapsed_seconds, command)) {
    // 使用项目转换并提交本次结果。
}

// 无累计的两种形式，输入仍是同一组目标/测量数据。
SMC::PowerPosition power_axis;
SMC::TerminalPosition terminal_axis;
bool power_ready = power_axis.Init(power_config, project_min, project_max);
bool terminal_ready = terminal_axis.Init(terminal_config, project_min, project_max);
```

配置变量和project_*是待项目提供的量，不是默认参数。各电机分别创建实例，同一实例串行调用。原参考代码不加入固件，只编译main/ALG_SMC.cpp。

## 6. 实际验证与入口

新增四项主机测试后共13项，新增504组独立double公式检查，覆盖累计、退化关系、正反输入、单位变换、两侧分支、零和极小误差、复位、失败保持与实例独立。

总入口 [run_checks.m](../matlab/验证/run_checks.m) 同时验证位置、速度和位置扩展；单独入口为 [run_extensions_checks.m](../matlab/验证/run_extensions_checks.m)。扩展部分使用3558个公式点、八组各8000行闭环，其中一次暂停跳过500次Calc，共63500次真实计算；MATLAB独立推进对象，不读取C++后续状态或控制生成参考。

控制器按single精度独立复算，另保存double对照。新增pow与长序列的允许差预先设为 `3×10^-5+3×10^-5*|参考|`，真假状态要求一致；相邻对象状态重建阈值10^-12。该阈值没有因运行失败而放宽。

教学入口为第24～27讲各自的run_lesson.m。报告记录源码摘要、参数、输入和首次超差位置，保存在build/验证/位置扩展及build/教学对应目录。强限幅案例只核对公式和数据路径，不预设8秒内收敛；累计值与实际误差如实保留。

含三个新类的生产文件已进行M4/M7目标编译。幂次计算依赖工具链的数学运行库，静态库编译不证明具体固件已经链接。尚无本次功能的固件完整链接、上板、电机或整车验证。
