# 第 06 讲：滑模变量和滑模面分别是什么

前置内容是[误差与误差变化率](02_误差与误差变化率.md)、[误差相平面](05_误差相平面.md)。本讲只定义和检查一条关系，不计算控制输出，也不分析面内误差的完整时间过程。

## 1. 先重述两个坐标

- e 是实际角度减目标角度，单位 °。
- ė 是 e 随时间的变化率，等于实际角速度减目标角速度，单位 °/s。

相平面用 e 作横坐标、ė 作纵坐标。一个点 `(e,ė)` 就记录当时的两个量。

## 2. 滑模变量是什么

**滑模变量是按选定关系，把误差及其变化率组合后算出的一个数。** 本讲记为 s。

组合前引入系数 c，它是正数，单位为 1/s，也就是每秒。这样 `c×e` 与 ė 都是 °/s，可以相加。本讲选用：

```text
s = ė + c × e
```

s 的单位为 °/s。c 用来规定误差与误差变化率之间的关系，本讲只用一个固定的教学数值，不讨论实机整定。

取教学假设 `c=.5 /s`，位置误差为 +10°，则 `c×e=5°/s`：

| e | ė | c×e | 算出的 s |
| --- | --- | --- | --- |
| +10° | −2°/s | +5°/s | +3°/s |
| +10° | −5°/s | +5°/s | 0°/s |
| +10° | −8°/s | +5°/s | −3°/s |

因此 s 不是原来的位置误差，也不是输出电流。它是用这条公式得到的新量。

## 3. 滑模面是什么

**滑模面是所有让滑模变量等于零的点放在一起形成的关系。** 在本讲就是所有满足下面条件的 `(e,ė)`：

```text
s = 0
ė + c × e = 0
ė = -c × e
```

在当前这个二维相平面里，这些点排成一条过原点的直线；沿用术语仍称“滑模面”。本例 c=.5 /s，这条线就是 `ė=−.5×e`。

例如 `(10,−5)` 在面上，因为 `−5+.5×10=0`；`(−10,5)` 也在面上；原点 `(0,0)` 同样在面上。

要分清两个对象：s 是给一个点算出的数，滑模面是所有使这个数为零的点。

## 4. s 的正负在图上怎样看

对于同一个横坐标 e，滑模面规定了纵坐标应为 `−c×e`。实际点的纵坐标与这个值之间的差，恰好就是 s：

```text
s = 实际误差变化率 - 线上对应的误差变化率
```

例如 e=10° 时，线上应为 −5°/s：

- 实际变化率是 −2°/s，点在线的上方，s=+3°/s。
- 实际变化率是 −5°/s，点在线上，s=0。
- 实际变化率是 −8°/s，点在线的下方，s=−3°/s。

这里的上方/下方比较是在相同 e 下进行的。s 的单位是 °/s，表达纵坐标数值之差，不把它直接当作点到直线的最短几何距离。它的正负也不直接等同位置误差正负、正在靠近还是远离目标，或者最终电流的正负。

## 5. s=0 不代表 e=0

点 `(10,−5)` 已经满足 s=0，但它的位置误差仍为 +10°。这个条件规定的是“误差为 +10° 时，误差变化率应为 −5°/s”。

若误差为负，同一条关系要求变化率为正。例如 `(−10,5)`。所以在 c>0 时，线上非零误差对应的变化方向都指向零误差一侧。

但只知道某个时刻落在线上，还不能断言它以后一直沿着线运动。本讲画的直线是所规定的关系，没有模拟一个控制器把物体带到线上或维持在线上。

“如果一直满足这条关系，误差怎样随时间变化”是下一讲的问题；“怎样计算输出使系统到达并保持这条关系”还需要后续推导。

## 6. 与开源和当前库逐项对应

川大 [SMC_Doc.tex](../Sliding/Documentation/SMC_Doc.tex) 第 93～95 行选用 `s=ce+ė`，即本讲这条关系。普通位置分支 [Sliding.cpp](../Sliding/code/Sliding.cpp) 第 144 行：

```cpp
smc.s = smc.param.c * smc.error.p_error + smc.error.v_error;
```

`p_error` 对应 e，`v_error` 对应误差变化率，`param.c` 对应 c，`smc.s` 是本讲的滑模变量。

复旦旧版 [slidingmodec.cpp](../SMC_Controller/SMC/slidingmodec.cpp) 第 21 行写成 `s=C*error+(ang_vel-dref)`，采用同样的组合思路。其目标差分 dref 没有按时间归一化的问题已在第 4 讲说明，不能直接忽略单位差异。

当前库 [ALG_SMC.cpp](../main/ALG_SMC.cpp) 第 87～88 行：

```cpp
const float position_term = config_.surface_gain * next.error;
next.sliding_variable = next.error_rate + position_term;
```

`surface_gain` 就是 c，头文件声明单位为 1/s。`sliding_variable` 是 s。这里的 `position_term` 不是独立控制器，只是 `c×e` 这一项的中间数值。

本讲只对应这两项相加，不展开下方的控制输出公式。

## 7. MATLAB 实验

入口：[run_lesson.m](../matlab/教学/第06讲_滑模变量与滑模面/run_lesson.m)，或在根目录 [start.m](../start.m) 设置 `mode='教学'、number=6`。仅依赖 MATLAB，不需要 C++、Simulink 或额外工具箱。

所有参数是教学假设：c=.5 /s；三个正误差点均为 +10°，变化率分别为 −2、−5、−8°/s；另检查 `(−10,5)` 和原点。它们不是原开源实机参数，也不作为库默认配置。

左图画零值直线与各点，右图画同一 e=10° 时的 s 数值。图中没有时间轴、运动箭头或对象仿真，不把这条线直接当成物体已经走过的轨迹。

程序核对五个手算点的 s、哪些点使 s=0、同一 e 下的上方/下方，以及直线上 65 个点的零值关系，并验证“s=0 时位置误差可以非零”。

输出在 `build/教学/第06讲_滑模变量与滑模面/`，保留 PNG、FIG、手算点 CSV、直线点 CSV、MAT 参数数据和 JSON 报告。`on_surface` 表示本组准确给定的点是否满足 s=0，`sliding_variable_deg_s` 是滑模变量，单位 °/s。

生产库和三个参考未修改。实验通过只说明本讲公式与几何关系核对通过，不代表已验证面内运动、控制输出或硬件性能。
